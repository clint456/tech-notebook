# 硬件实战学习路线（对标上面难度梯队，由简到难、项目驱动、闭环落地）

> 适配你现状：嘉立创EDA熟练、会画双层板、Buck电源踩过发烫/异响坑，模电基础仅到MOS之前。 学习原则：**按电路难度梯队依次通关，做完一类模块再进阶下一档；边做边补理论，不脱产啃整本教材**。 每一级 = 【理论要点 + 实操项目 + PCB设计重点 + 测试验证任务 + 遇到问题补哪些模电】。

## 总进阶路线图（和难度表一一对应）

阶段0：基本功巩固 → 阶段1：简单IO+低速通信 → 阶段2：Buck开关电源攻坚（你的当前关卡）→ 阶段3：模拟采集+差分总线 → 阶段4：中高速接口 → 阶段5：四层板+高速难题

------

# 阶段0｜前置基本功（1‑2周，不上大功率）

### 目标

原理图模块化分页、规范BOM、DFM检查、看懂datasheet参考电路、电流线宽计算。

### 实操项目

STM32最小系统底板 + LDO供电(5V‑3.3V) + LED+按键

- 电路模块：LDO电源、GPIO、复位、晶振、UART
- PCB重点：
  1. 晶振靠近MCU，去耦电容紧贴电源引脚
  2. 分区：主控区、接口区
- 测试任务：串口打印，按键控制LED，无电源噪声问题即可
- 需要补理论：电阻分压、电容去耦原理
- 过关标准：板子一次上电成功，无虚焊、原理图、BOM、Gerber全套生产文件输出无误

------

# 阶段1｜低速数字通信模块（⭐~⭐⭐，2‑3周）

> 电路：UART、I2C、低速SPI，<10MHz

### 项目A：I2C外设板

STM32 + I2C‑OLED + 温湿度传感器SHT30

- PCB要点：上拉电阻靠近SDA/SCL；走线无苛刻长度要求；远离后面电源电感预留位置
- 测试：连续读取传感器数据，无丢包乱码

### 项目B：低速SPI项目

STM32 + SPI W25Q64（Flash）

- PCB要点：CS、SCLK、MOSI/MISO走线短，暂时不用等长
- 测试：反复读写Flash，长时间跑不报错

> 过关目标：彻底熟悉三大低速总线，知道什么叫**数字信号被干扰**。 理论按需补：开漏输出、上拉电阻作用。

------

# 阶段2｜开关电源专项攻坚（⭐⭐⭐ ~ ⭐⭐⭐⭐，重中之重，4‑6周，你现在所处关卡）

> 模块：异步Buck、同步PWM‑Buck、COT‑Buck、LDO后级滤波 目标：根治发烫、振荡、滋滋异响、EMI干扰SPI信号三大故障

## 项目1：异步Buck 24V→5V‑5A（TPS5450）复盘优化版

PCB强制遵守Buck黄金布局三原则

1. 开关环路面积最小
2. FB反馈走线远离电感，采样点放在输出电容后端
3. 功率地与信号地单点汇合 测试清单（必须上示波器，不能只看电压）

- 输出纹波大小
- 满载时续流二极管温度
- 观察有没有音频异响；SPI Flash放在板子上，验证电源会不会干扰SPI通信

## 项目2：同步PWM‑Buck（SCT2452，宽压36V，无COT）

对比异步版本，观察去掉二极管之后发热改善情况 重点对比：异步 vs 同步的发热差异

## 项目3：COT架构同步Buck（SY8210）

刻意练习：ESR电容搭配，解决COT芯片滋滋振荡问题

> 这三个电源做完，你工控电源基础就过关。 按需补理论（核心）：电感续流、电感饱和、MOS开关损耗、电容ESR、负反馈环路稳定性。

> 过关标准：3块电源满载稳定，无振荡异响，SPI信号不受电源噪声干扰。

------

# 阶段3｜模拟信号 + 差分工业总线（⭐⭐⭐⭐，1个月）

模块：ADC电压采集、运放放大、CAN总线

## 项目A：带Buck电源的模拟采集综合板

24V‑5V Buck + STM32 + ADC多路电压采样 **核心训练主题：开关电源噪声对模拟信号的干扰隔离** PCB硬性规则：

1. 模拟采集区和电源电感对角线放置，拉开距离
2. 模拟地‑数字地单点星型接地
3. 采样信号线禁止跨功率分割区 测试：空载、满载时ADC读数会不会跳变，判断电源噪声有没有串进模拟电路。

## 项目B：CAN总线工控板

STM32 + TJA1050 CAN收发器 + Buck电源 PCB要点：CAN_H、CAN_L走线平行等长；120Ω终端电阻放在总线末端，远离开关电源电感。 测试：长距离CAN通信，无丢包。

> 按需补理论：差分信号、运放虚短虚断、有源RC滤波。

------

# 阶段4｜中‑高速接口电路（⭐⭐⭐⭐⭐，1‑2个月）

模块：高速SPI、USB2.0

## 项目：STM32+USB2.0(FS全速)+高速SPI屏幕

PCB训练重点：

1. USB D+/D‑差分对内等长，阻抗90Ω

2. > 20MHz高速SPI，时钟走线优先，控制走线长度

3. 高速信号线严格远离Buck电感、功率走线 测试：USB通信稳定，高速SPI刷屏无花屏。

> 按需补理论：差分信号、信号反射、串扰，3W布线规则。

------

# 阶段5｜进阶分水岭：四层板综合工控项目（⭐⭐⭐⭐⭐，长期）

> 前面全部双层板通关之后，再进入四层板，不建议过早上手。

## 项目：4层工控采集板

叠层：顶层信号‑完整地平面‑电源平面‑底层信号 功能：24V Buck供电 + STM32 + CAN + ADC多路采集 + SPI外设 训练目标：

- 完整地平面的优势、电源分割规则
- 地平面如何降低开关电源噪声，解决模拟信号干扰难题

可选后续高阶方向二选一

### 路线A（工控‑电源硬件，匹配你当前方向）

Boost升压电源、反激隔离电源、EMC整改、热设计，示波器电源环路稳定性测试

### 路线B（高速数字方向）

以太网、DDR、射频WIFI蓝牙项目，阻抗控制，等长布线，信号完整性SI

------
