当开发板上的 MQTT Broker 服务已经在使用端口 1883，所以当你尝试启动 Docker 容器时，发生了端口冲突。要解决这个问题，你需要停止已有的 MQTT 服务，释放端口 1883。下面是一些步骤，你可以尝试：

1. **查看 MQTT 服务进程**： 可以使用以下命令查看哪个进程占用了端口 1883：

```bash
sudo lsof -i :1883
```

或者使用：

```bash
sudo netstat -tuln | grep 1883
```

2. **停止 MQTT 服务**： 一旦你找到了正在占用端口 1883 的服务（通常是 `mosquitto` 或其他 MQTT 服务），可以停止它：

```bash
sudo systemctl stop mosquitto
```

或者如果你知道进程的 PID（进程 ID），也可以直接终止该进程：

```bash
sudo kill <PID>
```

3. **检查端口是否已经释放**： 确认端口已经释放：

```bash
sudo lsof -i :1883
```

4. **重新启动 Docker 容器**： 一旦端口 1883 释放，你可以重新启动你的 Docker 容器。

如果你不打算关闭 MQTT 服务，你也可以考虑更改 Docker 容器映射的端口，避免与已有服务冲突。
