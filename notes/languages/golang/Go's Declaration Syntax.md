### **笔记：Go 的声明语法**
#### **引言**
+ 新手常疑惑为何 Go 的声明语法与 C 家族传统不同。
+ 本文对比两种方法，解释 Go 选择当前语法的原因。

---

#### **C 的语法**
1. **特点**：
    - C 使用独特的方式：通过表达式推导类型，将基础类型写在左侧，变量表达式写在右侧。
    - 示例：
        * `int x;` → `x` 是 `int` 类型。
        * `int *p;` → `*p` 是 `int`，所以 `p` 是指针。
        * `int a[3];` → `a[3]` 是 `int`，所以 `a` 是数组。
2. **函数声明**：
    - 早期：`int main(argc, argv) int argc; char *argv[];`
    - 现代：`int main(int argc, char *argv[]);`
    - 逻辑一致：`main(argc, argv)` 返回 `int`。
3. **复杂情况**：
    - 函数指针：`int (*fp)(int a, int b);` → `(*fp)(a, b)` 返回 `int`。
    - 更复杂：`int (*fp)(int (*ff)(int x, int y), int b);` → 可读性下降。
    - 无参数名：`int (*fp)(int (*)(int, int), int);` → 更难理解。
    - 返回函数指针：`int (*(*fp)(int (*)(int, int), int))(int, int);` → 几乎不可读。
4. **问题**：
    - 类型和表达式语法相同，复杂时难以解析。
    - 需括号区分类型，如 `(int)M_PI`。

---

#### **Go 的语法**
1. **特点**：
    - 类型语法独立于表达式，名称在前，类型在后。
    - 示例（对比 C）：
        * `x int`（C: `int x;`）
        * `p *int`（C: `int *p;`）
        * `a [3]int`（C: `int a[3];`）
2. **优点**：
    - 从左到右阅读清晰，简洁（去掉冒号和冗余关键字）。
    - 类型与表达式无直接对应，但更直观。
3. **函数声明**：
    - 示例：`func main(argc int, argv []string) int`
    - 无参数名：`func main(int, []string) int`
    - 可读性高，参数和返回值顺序明确。
4. **复杂类型**：
    - 函数变量：`f func(func(int,int) int, int) int`
    - 返回函数：`f func(func(int,int) int, int) func(int, int) int`
    - 始终清晰，名称在前，类型逐级展开。
5. **闭包**：
    - 类型和表达式分离，便于编写闭包：
        * `sum := func(a, b int) int { return a+b } (3, 4)`

---

#### **指针的特殊性**
1. **与 C 的联系**：
    - Go 保留 `*` 表示指针，如 `var p *int; x = *p`。
    - 未采用后缀 `*`（如 `p*`），避免与乘法混淆。
2. **可能的改进**：
    - 若用 Pascal 的 `^`（如 `var p ^int; x = p^`），语法更统一，但未采纳。
    - 前缀 `*` 导致需括号区分类型，如 `(*int)(nil)`。
3. **折中**：
    - 指针语法受 C 影响，未能完全摆脱括号。

---

#### **总结**
+ **C 的问题**：类型和表达式耦合，复杂时混乱（“顺时针/螺旋规则”）。
+ **Go 的优势**：类型语法独立，从左到右清晰，复杂类型更易懂。
+ **权衡**：指针保留 C 风格，略有不便，但总体更简洁直观。
