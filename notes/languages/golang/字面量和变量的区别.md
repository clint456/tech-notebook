**字面量（Literal）** 和 **变量（Variable）** 在 C++ 中是两个不同的概念，主要区别如下：

| 对比项 | **字面量（Literal）** | **变量（Variable）** |
| --- | --- | --- |
| **定义** | 代码中直接出现的固定值 | 用于存储数据的命名标识符 |
| **是否可变** | **不可变**，它本身的值不会变 | **可变**，变量的值可以在程序运行时改变 |
| **存储方式** | 直接存在代码中，编译时确定 | 存储在内存中，运行时可以修改 |
| **是否有名称** | **没有名称**，是一个直接值 | **有名称**，通过变量名访问 |
| **示例** | `42`, `3.14`, `"Hello"` | `int x = 42;`, `double y = 3.14;` |
| **作用** | 提供具体值 | 存储数据，并可进行运算、传递等操作 |


---

### **示例解析**
#### **1. 字面量**
字面量是直接出现在代码中的固定值，例如：

```cpp
int x = 10;  // 10 是一个字面量
double pi = 3.14;  // 3.14 是一个字面量
std::string text = "Hello";  // "Hello" 是字符串字面量
```

在这里：

+ `10`、`3.14`、`"Hello"` 都是字面量，它们是固定值，不能更改。

#### **2. 变量**
变量是一个命名的存储单元，可以存储和修改数据：

```cpp
int a = 5; // 变量 a 存储整数 5
a = 10;    // 变量 a 现在被赋值为 10
```

在这里：

+ `a` 是变量，它的值可以从 `5` 变为 `10`。

#### **3. 变量和字面量的关系**
变量通常是通过字面量初始化的：

```cpp
int number = 100; // 100 是字面量，number 是变量
```

但变量的值可以更改，而字面量的值是固定的：

```cpp
number = 200; // 变量的值变了
```

但 `100` 这个字面量不会改变，它依然是 `100`，只是 `number` 这个变量存储的值从 `100` 变成了 `200`。

---

### **补充：字面量的类型**
C++ 支持不同类型的字面量：

+ **整数字面量**：`42`, `0b1010`（二进制）, `052`（八进制）, `0x2A`（十六进制）
+ **浮点字面量**：`3.14`, `2.5e3`
+ **字符字面量**：`'A'`, `'\n'`
+ **字符串字面量**：`"Hello"`
+ **布尔字面量**：`true`, `false`
+ **指针字面量**：`nullptr`

变量可以存储这些字面量，但变量本身可以变化：

```cpp
int x = 42;  // 42 是字面量，x 是变量
x = 100;     // 变量 x 的值变了，但 42 这个字面量依然是 42
```

---

### **总结**
1. **字面量是固定值**，如 `100`、`3.14`、`"Hello"`，它们不会改变。
2. **变量是存储数据的容器**，可以存储字面量，并且其值可以更改。
3. **字面量没有名称**，而**变量有名称**，可以通过变量名访问和修改数据。
4. **字面量的值在编译时确定**，而变量的值可以在运行时被修改。
