# 进程

进程指正运行的程序，CPU分配的最小单位，可以通过`ps` or `top`等命令查看正在运行的进程，线程是系统最小的调度单位，一个进程苦于拥有多个线程，同一个进程里的线程可以共享此进程的同一资源。

## 进程创建

所有的进程都是由其他进程创建（出来pid为0号idle进程），pid号为1的init进程是系统启动后运行的第一个进程，是所有进程的父进程，init进程会初始化一部分系统服务，创建其他进程。

创建新进程的那个进程称为父进程，新进程称为子进程，父进程和子进程拥有相同的代码段和数据段，有各自独立的地址空间。采用写时的拷贝技术（创建的新进程不会立即把父进程的资源空间复制过来，只有在修改时才会复制资源，另外父进程挂起的信号和文件锁不会被子进程集成）。

子进程结束后，它的父进程要收回它的资源，否则就会成为僵尸进程。

如果父进程先结束，子进程会被init进程收养，称为孤儿进程。



## getpid

| getpid函数功能      | 获取进程PID                                       |
| ------------------- | ------------------------------------------------- |
| 头文件              | #include <sys/types.h>\|<br />#include <unistd.h> |
| 返回值              | PID号                                             |
| pid_t getpid(void)  | 获取此进程PID                                     |
| pid_t getppid(void) | 获取父进程PID                                     |

```c
// 实验代码：通过程序创建子进程，并获取父、子进程PID号
#include <stdio.h>
#include <unistd.h>

int main(void)
{
  pid_t pid;
  pid = fork();
  if (pid < 0)
  {
    printf("fork is error\n");
    return -1;
  }
  // 父进程
  if (pid > 0) {
    printf("This is parent, parent pid is %d\n",getppid());
  }
  // 子进程
  if (pid == 0){
    printf("This is child, child pid is %d\n",getpid());
  }
  return 0;
}
```



## exec函数族

用fork函数创建子进程后，子进程往往会调用exec函数以执行另一个程序，该子进程被新的程序替换，改变地址空间、进程映像和一些属性，但是pid号不变。

| 函数          | int execve(const char *filename, char *const argv[], char *const envp[]); |
| ------------- | ------------------------------------------------------------ |
| 头文件        | #include <unistd.h>                                          |
| 参数 filename | 路径名，表示载入进程空间的新程序路径                         |
| 参数argv[]    | 命令行参数，argv[0]为命名名                                  |
| 参数envp[]    | 新程序的环境变量                                             |
| 返回值        | 成功：不返回，可通过errno检查                                |

![image-20250714171356857](https://raw.githubusercontent.com/clint456/PicGo/main/Linux%E9%A9%B1%E5%8A%A8/image-20250714171356857.png)

```c
// 实验代码：创建子进程
#include <stdio.h>
#include <unistd.h>
#include <stdlib.h>

int main(void)
{
    int i = 0;
    pid_t pid;
    pid = fork();
    if  (pid < 0)
    {
        printf("fork is error \n");
        return -1;
    }
    // 父进程
    if (pid > 0){
        printf("this is parent, parent pid is %d\n",getppid());
    }
    // 子进程
    if (pid == 0){
        printf("this is child, child pid is %d\n",getpid());
        execl("/home/clint/child","child",NULL);
        exit(1);
    }
    i++;
    printf("i is %d\n",i);
    return 0;
}

// 实验代码：子进程

```

### 进程的状态：

| D    | 无法中断的休眠状态                                      |
| ---- | ------------------------------------------------------- |
| R    | 正在执行中                                              |
| S    | 静止状态                                                |
| T    | 暂停执行                                                |
| Z    | 不存在但暂时无法消除                                    |
| W    | 没有足有的记忆体分页可分配                              |
| <    | 高优先序的行程                                          |
| N    | 低优先序的行程                                          |
| L    | 有记忆体分页分配并锁在记忆体内（实时系统或 [?] A  I/O） |

## 孤儿进程与僵尸进程

- 孤儿进程：父进程结束后，子进程还未结束，这个子进程就叫做孤儿进程。
- 僵尸进程：子进程结束后，父进程还在运行，但是父进程不去释放进程控制模块，这个子进程就叫僵尸进程。



## wati()函数

wait()函数一般用在父进程中等待回收子进程的资源，而防止僵尸进程的产生：

| 函数   | pid_t wait(int *status)       |
| ------ | ----------------------------- |
| 头文件 | #include <sys/wait.h>         |
| 返回值 | 成功返回子进程pid，失败返回-1 |
