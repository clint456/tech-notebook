# 库的制作与使用

库是一种可执行的二进制文件，是编译好的代码。使用库可以提高开发效率。在Linux下有静态库与动态库。

- 静态库在程序编译的适合就会被链接到目标代码里面。在程序运行的时候就不需要静态库，因此编译出来的体积会比较大。以`lib`开头，以`.a`结尾;
- 动态库（也叫共享库）在程序编译的时候不会被链接到目标代码里，而是在程序运行的时候被载入。因此程序运行的时候需要动态库。因此体积比较小。以`lib`开头，以`.so`结尾。

## 静态库的制作

1. 编写或准备库的源代码；
2. 将源码.c编译生成.o文件；
3. 使用`ar`命令创建静态库’
4. 测试库文件。

>  libmylib.a ：库文件
>
> mylib：库名

## 动态库的制作

1. 编写或准备库的源代码；
2. 将源码.c编译生成.o文件；
3. 使用`gcc`创建动态库
4. 测试库

> gcc test.c -lmylib -L
>
> - `-l` 指定动态库名
> - `-L` 指定动态库的查找位置（在当前目录寻找）

## 实验：静态库的制作

```c
// mylib.c
#include <stdio.h>
void mylib(void);
void mylib(void)
{
  printf("This is mylib\n");
}

//test.c
#include <stdio.h>
void mylib(void);
int main(void){
  mylib();
  return 0;
}
```

## 实验：动态库的制作

```c
// mylib.c
#include <stdio.h>
void mylib(void);
void mylib(void)
{
  printf("This is mylib\n");
}

//test.c
#include <stdio.h>
void mylib(void);
int main(void){
  mylib();
  return 0;
}
```

生成后，发现系统并不能找到动态库，是因为系统默认回去使用`/lib`  `/user/lib`中查找动态函数库，如果不在就会出现以上问题。

有如下三种解决办法：

- 将.so文件拷贝到指定目录下
- 在动态库所在路径添加到环境变量

![image-20250714005623925](https://raw.githubusercontent.com/clint456/PicGo/main/Linux%E9%A9%B1%E5%8A%A803%20%E5%8A%A8%E6%80%81%E5%BA%93%E5%88%B6%E4%BD%9C02.png)

- 修改中`/etc/ld.so.conf`在这个配置文件中加入动态库所在位置，然后使用命令`ldconfig`更新目录
