# 目录IO

## 目录IO与文件IO对比
| 目录IO             | 文件IO          |
| ------------------ | --------------- |
| opendir  打开目录  | open  打开文件  |
| mkdir  创建目录    |                 |
| readdir  读取目录  | read  读文件    |
| closedir  关闭目录 | close  关闭文件 |

区别： 我们知道文件IO与标准IO都是对文件操作，接下里学习的目录IO都是对应目录的操作。

## `mkdir`

| 函数         | int mkdir(const char *pathname,mode_t_mode)                  |
| ------------ | ------------------------------------------------------------ |
| 头文件       | #include <sys/stat.h>                                        |
| 参数pathname | 路径和文化名。                                               |
| 参数mode     | 权限掩码，对于不同用户和设置可执行、读、写（x、r、w)权限，使用八进制表示，此参数可不写。 |
| 返回值       | mkdir()执行成功会返回0，出错返回-1                           |

```c
// 实验代码：创建一个权限为666的文件
#include <stdio.h>
#include <stdlib.h>
#include <sys/stat.h>
#include <sys/types.h>

int main(int argc, char *argv[])
{
  int ret;
  if(argc !=2 )
  {
    printf("uage:%s <name file\n",argv[0]);
    return -1;
  }
  ret = mkdir(argv[1],0666);
  if(ret<0)
  {
    printf("mkdir is error\n");
  }

  printf("mkdir is ok\n");
  return 0;
}
```

## `opendir()/closedir()`

| 函数     | DIR *opendir(const char *name);    |
| -------- | ---------------------------------- |
| 头文件   | #include <sys/types.h>             |
| 返回参数 | 路径名字                           |
| 返回值   | 成功返回打开的目录流，失败返回NULL |

| 函数     | int closedir(DIR *dirp) |
| -------- | ----------------------- |
| 头文件   | #include <sys/types.h>  |
| 参数dirp | 要关闭的目录指针流      |

```c
// 实验代码：打开一个文件目录流，然后再关闭
#include <stdio.h>
#include <stdlib.h>
#include <sys/stat.h>
#include <sys/types.h>
#include <dirent.h>



int main(int argc, char *argv[])
{
  int ret;
  DIR *dp;
  if (argc !=2){
    printf("Usage:%s <name file>\n", argv[0]);
    return -1;
  }
  dp = opendir(argv[1]);
  if (dp !=NULL){
    printf("opendir is ok\n");
    return -1;
  }
  closedir(dp);
  printf("opendir is closed\n");
  return 0;
}
```



##  `readdir()`

| 目录           | struct dirent *reddir(DIR *drip);<br />int readdir_r(DIR *dirp,struct dirent *entry,struct dirent **result); |
| -------------- | ------------------------------------------------------------ |
| 头文件         | #include <dirent.h>                                          |
| 参数 DIR *drip | 要读取的目录流指针                                           |
| 返回值         | 成功返回读到的指针流，失败返回NUL                            |

```c
// 实验代码：读取一个目录
#include <stdio.h>
#include <stdlib.h>
#include <sys/stat.h>
#include <sys/types.h>
#include <dirent.h>

int main(int argc, char *argv[])
{ int ret;
  DIR *dp;
  struct dirent *dir;
  if (argc != 2){
    printf("Uage:%s <name file>\n",argv[0]);
    return  -1;
  };
  dp = opendir(argv[1]);
  if (dp == NULL) {
    printf("opendir is error\n\n");
    return -2;
  }
  printf("opendir is ok\n");
  while(1)
  {
    dir = readdir(dp);
    if (dir!=NULL) {
      printf("file name is %s\n",dir->d_name);
    }
    else 
    break;
  }
  closedir(dp);
  return 0;
}
```
