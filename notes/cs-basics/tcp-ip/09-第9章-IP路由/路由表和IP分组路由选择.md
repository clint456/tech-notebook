### 例子4：给本机发送数据报
+ **四种方法**
    1. **使用主机名**：例如 `svr4`，解析为本机的IP地址（如 `140.252.13.34`）。
    2. **使用主机IP地址**：直接使用本机的IP地址（如 `140.252.13.34`）。
    3. **使用环回名**：例如 `localhost`，解析为 `127.0.0.1`。
    4. **使用环回IP地址**：直接使用 `127.0.0.1`。
+ **路由过程**
    - 如果目的地址是本机IP（如 `140.252.13.34`），路由表中可能有特定主机表项匹配。
    - 如果使用环回地址（`127.0.0.1`），会匹配路由表中的 `localhost` 表项。
    - 数据不会离开本机，而是通过内部环回接口（通常是 `lo0`）处理。
+ **解释**
    - 这四种方法最终都会将数据路由到本机，区别仅在于地址表示方式和解析过程。

### 总结
+ 路由选择的基本步骤是：**主机地址匹配 → 网络地址匹配 → 默认路由**。
+ **直接路由**：目的主机在同一网络，链路层地址是目的主机的MAC地址。
+ **间接路由**：需要通过网关转发，链路层地址是网关的MAC地址。
+ 本机通信通常通过环回地址或本地IP实现。
