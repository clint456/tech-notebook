---

### **1. 背景与网络结构**
+ **网络地址**：`140.252.0.0/16`，这是一个 B 类地址，默认子网掩码为 `255.255.0.0`，提供 65,536 个 IP 地址。
+ **子网划分**：文中提到子网 `140.252.13.0`，并进一步对其进行划分，使用了变长子网掩码（VLSM）。
+ **子网号**：子网 `140.252.13.0` 的子网号有 11 位，其中：
    - 前 8 位固定为 `13`（即十进制的 13，二进制为 `00001101`）。
    - 后 3 位用于区分不同的子网类型：
        * `001` 表示以太网子网。
        * `010` 表示点对点 SLIP（Serial Line Internet Protocol）链路。
+ **子网掩码**：`255.255.255.224`（即 `/27`，或十六进制 `0xffffffe0`），这意味着：
    - 32 位 IP 地址中，前 27 位是网络号和子网号，后 5 位是主机号。
    - 每子网有 2^5 = 32 个地址，其中 30 个可用（减去网络地址和广播地址）。

### **2. IP 地址结构**
+ **子网号的构成**：
    - 总共 27 位网络部分（16 位原始网络号 + 11 位子网号）。
    - 前 16 位是 `140.252`（网络号）。
    - 接下来的 11 位是子网号，其中前 8 位固定为 `13`（即 `00001101`），后 3 位根据子网类型变化。
    - 最后 5 位是主机号。
+ **子网示例**：
    - 以太网子网：子网号后 3 位为 `001`，地址范围为 `140.252.13.32 - 140.252.13.63`。
        * 网络地址：`140.252.13.32`。
        * 广播地址：`140.252.13.63`。
    - SLIP 链路：子网号后 3 位为 `010`，地址范围为 `140.252.13.64 - 140.252.13.95`。
+ **路由器 sun**：
    - IP 地址：`140.252.1.29`。
    - 负责将数据报转发到子网 `140.252.13.0`。
    - 前提是路由器 sun 知道子网 `140.252.13.0` 使用 11 位子网号，并能正确解析。

### **3. 子网掩码的含义**
+ **子网掩码**：`255.255.255.224`（`/27`）：
    - 二进制：`11111111.11111111.11111111.11100000`。
    - 前 27 位为 1，表示网络和子网部分；后 5 位为 0，表示主机部分。
+ **主机数量**：每子网有 32 个地址（2^5），可用主机数为 30（去掉网络地址和广播地址）。
+ **作用**：子网掩码定义了子网的边界，确保路由器和主机能正确识别网络和主机部分。

---

### **4. 路由器和主机的角色**
+ **sun 和 bsdi**：
    - 既是主机（有 IP 地址），又是路由器（多接口，能转发数据包）。
    - 多接口设备可以在不同子网之间转发数据，例如 sun 将数据从 `140.252.1.0` 转发到 `140.252.13.0`。
+ **数据转发**：
    - 只要目标是子网 `140.252.13.0` 的数据报到达路由器 sun，且 sun 能识别 11 位子网号，就不会出现问题。

---

### **5. 广播地址**
+ **以太网子网的广播地址**：`140.252.13.63`。
    - 计算方法：
        * 网络地址为 `140.252.13.32`。
        * 主机部分 5 位全置为 1（即 `11111` = 31）。
        * `140.252.13.32 + 31 = 140.252.13.63`。
    - 这是一个**子网定向广播地址**（subnet-directed broadcast address），用于向子网内所有主机发送数据（详见第 12 章）。

---

### **6. VLSM 的应用**
+ **变长子网掩码**：
    - 子网 `140.252.13.0` 使用了 `/27` 掩码，但不同子网类型（以太网、SLIP）通过后 3 位区分。
    - 这种灵活性允许在同一网络中支持不同大小的子网。
+ **兼容性**：
    - 只要路由器和主机配置正确（知道掩码和子网结构），VLSM 不会引发问题。

6. **VLSM 优势**：通过不同子网号和掩码，灵活划分网络，避免地址浪费。
