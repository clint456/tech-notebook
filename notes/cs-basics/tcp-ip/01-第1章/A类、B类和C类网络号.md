# IPv4地址基础
IPvPv4地址是由32位二进制数组成，传统上采用“类”划分方式，将地址分为五大类，每一类的范围由地址的前几位（高位）决定。下面是对各类IP地址的详细说明：

### A 类地址
+ **范围**：0.0.0.0 到 127.255.255.255  
其中 0.x.x.x 通常用于特殊用途，而 127.x.x.x 被保留作回环（loopback）地址。
+ **结构**： 
    - **网络号**：前8位（最高位固定为0）
    - **主机号**：剩余24位
+ **可用网络号**：理论上有 2⁷ = 128 个网络号，但由于 0 和 127 被特殊用途占用，实际可用为 126 个。

### B 类地址
+ **范围**：128.0.0.0 到 191.255.255.255
+ **结构**： 
    - **网络号**：前16位（前两位固定为10）
    - **主机号**：后16位
+ **可用网络号**：2¹⁴ = 16,384 个

### C 类地址
+ **范围**：192.0.0.0 到 223.255.255.255
+ **结构**： 
    - **网络号**：前24位（前三位固定为110）
    - **主机号**：后8位
+ **可用网络号**：2²¹ = 2,097,152 个

### D 类地址（多播地址）
+ **范围**：224.0.0.0 到 239.255.255.255
+ **用途**：专门用于组播（Multicast），不用于常规的主机网络划分。

### E 类地址（保留地址）
+ **范围**：240.0.0.0 到 255.255.255.255
+ **用途**：保留用于科研或实验，不用于一般网络通信。

# 深入分析
#### A类网络
+ **二进制结构**：

```plain
0 | NNNNNNN | HHHHHHHH HHHHHHHH HHHHHHHH
```

    - 首位固定为0（1位）。
    - 网络号：第2到8位（7位可变）。
    - 主机号：后24位。
+ **地址范围**：
    - 最小值：0.0.0.0（二进制：00000000.00000000.00000000.00000000）
    - 最大值：127.255.255.255（二进制：01111111.11111111.11111111.11111111）
+ **网络号数量**：
    - 理论上，7位可变网络号 = (2^7 = 128)。
    - **保留地址**：
        * 0.0.0.0：全0网络，通常不用作实际网络标识。
        * 127.0.0.0：回环地址（如127.0.0.1用于本地测试）。
    - 实际可用网络号 = (128 - 2 = 126)。
+ **主机数量**：
    - 每网络的主机号24位，理论上 (2^{24} = 16,777,216)。
    - 减去全0（网络地址）和全1（广播地址），实际为主机数 = (16,777,214)。

#### B类网络
+ **二进制结构**：

```plain
10 | NNNNNN NNNNNNNN | HHHHHHHH HHHHHHHH
```

    - 前两位固定为10（2位）。
    - 网络号：第3到16位（14位可变）。
    - 主机号：后16位。
+ **地址范围**：
    - 最小值：128.0.0.0（二进制：10000000.00000000.00000000.00000000）
    - 最大值：191.255.255.255（二进制：10111111.11111111.11111111.11111111）
+ **网络号数量**：
    - 14位可变网络号 = (2^{14} = 16,384)。
    - 无特殊保留，全部可用。
+ **主机数量**：
    - 每网络的主机号16位，理论上 (2^{16} = 65,536)。
    - 减去全0和全1，实际为主机数 = (65,534)。

#### C类网络
+ **二进制结构**：

```plain
110 | NNNNN NNNNNNNN NNNNNNNN | HHHHHHHH
```

    - 前三位固定为110（3位）。
    - 网络号：第4到24位（21位可变）。
    - 主机号：后8位。
+ **地址范围**：
    - 最小值：192.0.0.0（二进制：11000000.00000000.00000000.00000000）
    - 最大值：223.255.255.255（二进制：11011111.11111111.11111111.11111111）
+ **网络号数量**：
    - 21位可变网络号 = (2^{21} = 2,097,152)。
    - 无特殊保留，全部可用。
+ **主机数量**：
    - 每网络的主机号8位，理论上 (2^8 = 256)。
    - 减去全0和全1，实际为主机数 = (254)。

# 更深入的考虑
1. **保留地址的影响**：
    - A类的0.0.0.0和127.0.0.0被排除在公共分配之外。
    - B类和C类没有类似的大范围保留，但私有地址（如10.0.0.0/8）会占用部分空间。
2. **实际分配**：
    - IANA（互联网号码分配机构）将这些地址分配给区域注册机构，部分地址被用作私有网络或特殊用途（如多播）。
3. **CIDR的替代**：
    - 现代网络已不再严格使用A、B、C类划分，而是采用CIDR（无类别域间路由），通过子网掩码灵活划分。

# 最终答案
+ **A类网络号最多**：126个。
+ **B类网络号最多**：16,384个。
+ **C类网络号最多**：2,097,152个。
