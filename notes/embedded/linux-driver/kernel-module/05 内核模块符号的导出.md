# 内核模块符号导出

这里的`符号`主要指的是`全局变量和函数`;

为什么需要导出符号？

1. Linux内核采用的是模块化的形式管理内核代码。内核每个模块相互之间是相互独立的。也就是说A模块的全局变量和函数是B模块无法访问的。
2. 有时候别人已经将部分函数实现好了，此时我们就希望调用他们的函数接口， 但是如何访问他们的接口呢？符号出

驱动程序编译生成的ko文件是相互独立的，模块间的资源（变量、函数）无法访问，一些复杂设备驱动需要进行分层，要求模块间通信，这个时候就需要内核符号导出。

内核符号导出指的是在内核模块中导出响应的函数和变量，在加载模块时被记录在公共内核符号表中，以供其它模块调用。符号导出所使用的宏为`EXPORT_SYMBOL(sym)`和`EXPORT_SYMBOL_GPL(sym)` 

`kernel/include/linux/export.h`
