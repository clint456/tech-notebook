# 注册字符设备号

## 字符设备号简介

Linux的设备管理是文件系统紧密结合的，各种设备都以文件的形式存放在`/dev`目录下，称为设备文件。应用程序可以打开、关闭和读写这些设备文件，完成对设备的操作，就像操作普通的数据文件一样。为了管理这些设备，系统为设备编了号，每个设备号又分为主设备号和次设备号。

主设备号用来区分不同类型的设备，而次设备用来区分同一类型的多个设备。

## 设备号的组成

一个字符设备或块设备都有一个主设备号和次设备号。主设备号和次设备号统称为设备号。主设备号用来表示一个特定的驱动程序。次设备号用来表示使用该驱动程序的各个设备。Linux提供了一个人为`dev_t`的数据类型表示设备号，`dev_t`定义在`include/linux/types.h`里面，定义如下：

```c
typedef __u32 __kernel_edv_t;
typedef __kernel_dev_t dev_t;
```

> `__` 前缀来表明这些符号是专门为内核内部使用的，避免与用户空间程序的符号冲突。

`dev_t`是一个32为变量，其中12位来表示主设备号，20位用来表示次设备号。因此Linux系统中主设备号范围为`0~4095`，所以大家在选择主设备号的时候一定不要超过这个范围，在文件`include/linux/kdev_t.h`中提供了几个操作设备哈的宏定义，如下图所示：

Linux提供了几个宏定义来操作设备号：

> ``` c
> #define MINORBITS 20 //次设备号的位数，一共是20位
> #define MINORMASK ((1U << MINORBITS) - 1 ) //次设备号的掩码
> #define MAJOR(dev) ((unsigned int)) ((dev) >> MINORBITS)) //在dev_t里面获取我们的主设备号号
> #define MKDEV(ma,mi)(((ma) << MINORBITS) | (mi))
> //将我们主设备号和次设备号组成一个dev_t类型
> //第一个参数是主设备号
> //第二个参数的次设备号
> ```

## 设备号的分配

### 静态分配设备号

静态分配设备号，就是驱动程序开发者通过静态指定一个设备号。对于一部分常用的设备，内核开发者已经为其分配 了设备号。这些设备号可以在内核源码`documentation/devices.txt`文件中找到。如果只有开发者自己使用这些驱动程序，那么其可以选择一个尚未使用的设备号。在不添加新硬件时，着各种方式不会产生设备号冲突。但是当添加新设备时，则很有可能造成设备号冲突，影响设备的使用。

使用`cat proc/devices`命令可以查看当前系统中所有已经使用了的主设备号。

### 动态分配设备号

由于静态分配设备号可鞥你存在冲突问题，建议使用动态分配设备号。在注册字符设备之前先申请一个设备号，系统会自动给你一个没有被使用的设备号，这样就避免了冲突。卸载驱动的时候释放这个设备号即可，设备号的动态申请函数如下：
