## 背景
在为 RK3568 平台编译 Linux 内核时，运行以下命令：

```bash
make rockchip_linux_defconfig
```

遇到以下错误：

```plain
/home/clint/RK3568/Ubuntu/Kernel/scripts/gcc-wrapper.py /home/clint/RK3568/Ubuntu/rk3568-ubuntu20.04-sdk-v1.0/sysroots/x86_64-linux/bin/gcc-arm-10.3-2021.07-x86_64-aarch64-none-linux-gnu/bin/aarch64-none-linux-gnu-gcc: unknown assembler invoked
scripts/Kconfig.include:47: Sorry, this assembler is not supported.
make[1]: *** [scripts/kconfig/Makefile:88：rockchip_linux_defconfig] 错误 1
make: *** [Makefile:639：rockchip_linux_defconfig] 错误 2
```

错误源于 `scripts/Kconfig.include` 中的汇编器检测逻辑：

```makefile
as-info := $(shell,$(srctree)/scripts/as-version.sh $(CC) $(CLANG_FLAGS))
$(error-if,$(success,test -z "$(as-info)"),Sorry$(comma) this assembler is not supported.)
```

该逻辑调用 `scripts/as-version.sh` 来检测汇编器 (`as`) 的名称和版本。如果 `as-info` 为空，则触发错误。

## 环境信息
+ **操作系统**：Ubuntu 20.04
+ **SDK 版本**：rk3568-ubuntu20.04-sdk-v1.0
+ **工具链**：gcc-arm-10.3-2021.07-x86_64-aarch64-none-linux-gnu
+ **工具链路径**：

```plain
/home/clint/RK3568/Ubuntu/rk3568-ubuntu20.04-sdk-v1.0/sysroots/x86_64-linux/bin/gcc-arm-10.3-2021.07-x86_64-aarch64-none-linux-gnu/bin/
```

+ **内核源码路径**：`/home/clint/RK3568/Ubuntu/Kernel`
+ **目标架构**：ARM64 (RK3568)
+ **编译命令**：

```bash
make ARCH=arm64 CROSS_COMPILE=/home/clint/RK3568/Ubuntu/rk3568-ubuntu20.04-sdk-v1.0/sysroots/x86_64-linux/bin/gcc-arm-10.3-2021.07-x86_64-aarch64-none-linux-gnu/bin/aarch64-none-linux-gnu- rockchip_linux_defconfig
```

## 错误分析
1. **错误详情**
    - `gcc-wrapper.py` 报错：

```plain
/home/clint/RK3568/Ubuntu/Kernel/scripts/gcc-wrapper.py ...: unknown assembler invoked
```

 表明 `gcc-wrapper.py` 在调用汇编器时失败。

    - `Kconfig.include:47` 报错：

```plain
Sorry, this assembler is not supported.
```

 表明 `as-version.sh` 未返回有效的汇编器信息（`as-info` 为空）。

2. **根本原因**
    - **工具链完整性**：手动运行 `as-version.sh` 返回 `GNU 23601`（GNU 汇编器 2.36.1），确认工具链中的 `aarch64-none-linux-gnu-as` 存在且可用：

```bash
/home/clint/RK3568/Ubuntu/Kernel/scripts/as-version.sh /home/clint/RK3568/Ubuntu/rk3568-ubuntu20.04-sdk-v1.0/sysroots/x86_64-linux/bin/gcc-arm-10.3-2021.07-x86_64-aarch64-none-linux-gnu/bin/aarch64-none-linux-gnu-gcc
```

    - **构建环境问题**：`make` 运行时，`gcc-wrapper.py` 可能干扰了 `as-version.sh` 的执行，导致汇编器检测失败。
    - **CLANG_FLAGS 不兼容**：`as-version.sh` 调用时传递了 `$(CLANG_FLAGS)`，但工具链是 GCC，可能引入了不兼容的参数。
    - **脚本逻辑问题**：`gcc-wrapper.py` 可能未正确处理汇编器调用，或者 `Kconfig.include` 未能正确解析 `as-version.sh` 的输出。
3. **相关问题**  
之前还遇到链接器 (`LD`) 配置错误（`binld not found`），表明工具链配置或脚本调用存在普遍问题。
