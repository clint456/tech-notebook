---

### 📌 问题描述
在执行 `make` 命令构建 kernel 镜像（如 `tl3568-evm.img`）时出现如下错误：

```bash
/usr/bin/env: "python": 没有那个文件或目录  
make: *** [arch/arm64/Makefile:215：tl3568-evm.img] 错误 127
```

### 📉 错误原因
+ 构建脚本中调用了 `python`，但系统中并没有 `python` 命令（Ubuntu 20.04+ 默认只有 `python3`）。
+ `/usr/bin/env python` 无法解析为实际的 Python 可执行文件，导致脚本执行失败。

---

### ✅ 解决方法
#### 方法一：创建符号软链接（推荐）
```bash
sudo ln -s /usr/bin/python3 /usr/bin/python
```

将 `python` 映射到系统已安装的 `python3`。

---

#### 方法二：修改脚本 shebang（不推荐）
将脚本中开头的：

```bash
#!/usr/bin/env python
```

改为：

```bash
#!/usr/bin/env python3
```

缺点：可能有多个脚本要改，不适用于批量处理。

---

### 🔍 验证 Python 是否已安装
```bash
which python3
```

若未安装，则执行：

```bash
sudo apt update
sudo apt install python3
```

---

### 💡 建议
+ 大部分 RK 平台 SDK 都是基于旧环境开发，推荐系统中保留 `python` 链接。
+ 若使用脚本打包镜像（如 `mkimg`、`check-atomics.sh`），Python 环境必须配置正确。
