


## 1、修改 rootfs 根文件系统镜像大小
默认的 rootfs.img 系统中的内存不足够安装 docker，这里参考 Rockchilp 官方文档【修改 rootfs 跟文件系统镜像】，将原容量为 3.4GByte 的根文件系统镜像扩大为 5GByte。

```bash
# 1、创建内容为空的rootfs-expanded.img镜像
dd if=/dev/zero of=rootfs-expanded.img bs=1G count=8

# 2、将 rootfs-expanded.img 格式化为 EXT4 格式
mkfs.ext4 rootfs-expanded.img

# 3、挂载 rootfs.img 根文件系统镜像
mkdir -p ./mount_dir
sudo mount -o loop rootfs.img ./mount_dir/

# 4、创建 mount_expanded 目录，并挂载 rootfs-expanded.img
mkdir -p ./mount_expanded
sudo mount -o loop rootfs-expanded.img ./mount_expanded/

# 5、将 rootfs.img 根文件系统镜像的所有文件迁移至 rootfs-expanded.img，
# 制作成新的 rootfs-expanded.img 根文件系统镜像
sudo mv ./mount_dir/* ./mount_expanded/
sync

# 6、挂载proc文件系统，并使用chroot进入rootfs-expanded.img镜像
sudo mount -t proc /proc ./mount_expanded/proc
sudo chroot ./mount_expanded

# 7、查看新制作的系统镜像容量
df -lh

# 8、退出文件系统并卸载
exit
sudo umount ./mount_expaned/proc
sudo umount -l ./mount_expaned
sudo umount -l ./mount_dir

# 9、删除原rootfs.img镜像，并将rootfs-expaneded.img镜像重命名
rm rootfs.img
mv rootfs-expaneded.img rootfs.img
```

## 3、rootfs 中安装 docker
1） 使用脚本 `mount_img.sh` 添加相应的文件系统并挂载 rootfs.img

```bash
# 1、挂载rootfs.img 
# -o loop: 使用循环设备来挂载rootfs.img,而不是物理设备
sudo mount -o loop rootfs.img ./mount_dir
# 2、挂载proc文件系统
# -t proc: 挂载制定类型为proc
# 该虚拟文件系统包含了系统内核、进程等相关信息，允许在rootfs.img中查看系统内核、进程等相关信息
sudo mount -t proc /proc ./mount_dir/proc/
# 3、挂载设备文件系统
# --bind：将现有的目录或文件挂载到另一个位置
# 使得设备文件目录能够在目标系统文件中访问
sudo mount --bind /dev ./mount_dir/dev
# 4、挂载/dev/pts文件系统
# 将现有的/dev挂载到./mount/dev/pts,使得目标文件系统能够使用终端设备
sudo mount --bind /dev/pts ./mount_dir/dev/pts
# 5、挂载运行时文件系统
# 提供运行时的信息，如进程、套接字、PID文件等
sudo mount --bind /run ./mount_dir/run
# 6、挂载/sys文件系统（如果需要硬件信息）
sudo mount -t sysfs sysfs ./mount_dir/sys/
# 7、挂载 /etc/resolv.conf （如果需要网络解析）
sudo mount --bind /etc/resolv.conf ./mount_dir/etc/resolv.conf
# 切换到目标文件系统
sudo chroot ./mount_dir
```

2）安装 Docker 在 rootfs 系统上

参照[Install Docker Engine on Ubuntu](https://docs.docker.com/engine/install/ubuntu/)

3）使用脚本 `umount_img.sh`，卸载 rootfs.img

```bash
#!/bin/bash

# 确保卸载顺序，从最上层开始
sudo umount ./mount_dir/run
sudo umount ./mount_dir/dev/pts
sudo umount ./mount_dir/dev
sudo umount ./mount_dir/proc
sudo umount ./mount_dir/sys  # 卸载 /sys
sudo umount ./mount_dir/etc/resolv.conf  # 卸载 DNS 配置

# 卸载 rootfs.img
sudo umount ./mount_dir

# 确保数据写入磁盘
sync

# 最后解除对 rootfs.img 的挂载
sudo umount rootfs.img

```

## 5、优化 docker 配置
1、默认情况下，Docker 会将镜像、容器、卷和日志等存储在系统的默认存储目录 `/var/lib/docker` 下  ，这将会使用 rootfs 根文件系统的内存，所以需要修改 docker 的存储目录

2、 docker 需要进行换源

3、docker 权限不足的问题，每次需要使用 sudo docker ~，需要修改用户组

因此通过 `update_docker_config.sh`脚本更新 docker 配置

:::info
**注意：需要确保 /userdata 目录已经进行挂载，否则需要先进行挂载设置**

:::

```bash
# 确认 userdata 分区的设备名，可以通过以下命令查看所有分区及其挂载点
lsblk

# 创建挂载点目录（如果尚未创建
sudo mkdir -p /mnt/userdata

# 编辑 /etc/fstab 文件，添加一行来自动挂载 userdata 分区
sudo vim /etc/fstab
# --》 添加 /dev/mmcblk0p9  /mnt/userdata  ext4  defaults  0  2

# 手动挂载 userdata 分区
sudo mount -a

#  验证挂载是否成功
df -h
```

```bash
#!/bin/bash

set -e  # 如果出错立即退出

# 检查 Docker 是否已安装
if ! command -v docker &> /dev/null; then
    echo "Docker is not installed. Please install Docker first."
    exit 1
fi

# 备份现有的 daemon.json
if [ -f /etc/docker/daemon.json ]; then
    echo "Backing up existing daemon.json..."
    sudo cp /etc/docker/daemon.json /etc/docker/daemon.json.bak
    echo "Backup created at /etc/docker/daemon.json.bak"
else
    echo "No existing /etc/docker/daemon.json found, skipping backup."
fi

# 创建 /etc/docker 目录（如果不存在）
echo "Creating /etc/docker directory..."
sudo mkdir -p /etc/docker

# 创建新的 Docker 存储路径目录
echo "Creating /mnt/userdata/docker directory..."
sudo mkdir -p /mnt/userdata/docker
sudo chown root:root /mnt/userdata/docker
sudo chmod 755 /mnt/userdata/docker

# 检查 /mnt/userdata/docker 是否有正确的权限
if [ "$(stat -c %U /mnt/userdata/docker)" != "root" ]; then
    echo "Warning: /mnt/userdata/docker directory does not have the correct ownership. Fixing..."
    sudo chown root:root /mnt/userdata/docker
fi

# 验证并写入新的 Docker 配置
echo "Writing new Docker registry-mirrors configuration..."
cat <<-'EOF' | sudo tee /etc/docker/daemon.json > /dev/null
{
    "registry-mirrors": [
        "https://docker.m.daocloud.io",
        "https://docker.imgdb.de",
        "https://docker-0.unsee.tech",
        "https://docker.hlmirror.com",
        "https://cjie.eu.org"
    ],
    "data-root": "/mnt/userdata/docker"
}
EOF

# 确保配置文件写入成功
if [ ! -f /etc/docker/daemon.json ]; then
    echo "Error: Failed to write /etc/docker/daemon.json."
    exit 1
fi

echo "Docker configuration updated successfully."

# 重新加载并重启 Docker 服务
echo "Reloading Docker and restarting service..."
sudo systemctl daemon-reload
sudo systemctl restart docker

# 添加当前用户到 Docker 用户组
echo "Adding current user to docker group..."
sudo gpasswd -a $USER docker
# 立即生效 Docker 用户组变更

echo "Applying new group membership..."
newgrp docker

# 验证 Docker 服务是否正常启动
if systemctl is-active --quiet docker; then
    echo "Docker is running successfully."
else
    echo "Error: Docker service failed to start. Please check the logs."
    exit 1
fi

echo "Docker configuration updated and Docker service restarted successfully."


```
