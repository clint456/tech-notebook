在 FreeRTOS 中，消息队列（Queue）是任务间通信的一种重要机制。通过消息队列，任务可以安全地交换数据，并在不同任务之间传递信息。FreeRTOS 提供了丰富的 API 来管理消息队列。以下是所有与消息队列相关的函数及其用途：

### 1. **`xQueueCreate()`**

**描述**：创建一个消息队列。

* **原型**：

  ```c
  QueueHandle_t xQueueCreate(UBaseType_t uxQueueLength, UBaseType_t uxItemSize);
  ```
* **参数**：

  * `uxQueueLength`：队列中可存储的最大消息数量。
  * `uxItemSize`：每个消息的大小（以字节为单位）。
* **返回值**：

  * 成功：返回队列句柄。
  * 失败：返回 `NULL`。

### 2. **`xQueueSend()`**

**描述**：向队列发送一个消息（将一个数据项放入队列的尾部）。

* **原型**：

  ```c
  BaseType_t xQueueSend(QueueHandle_t xQueue, const void *pvItemToQueue, TickType_t xTicksToWait);
  ```
* **参数**：

  * `xQueue`：队列句柄。
  * `pvItemToQueue`：指向待发送数据的指针。
  * `xTicksToWait`：等待队列空位的时间（单位为 tick）。如果设置为 `0`，则不等待。
* **返回值**：

  * `pdPASS`：消息成功发送。
  * `errQUEUE_FULL`：队列已满，消息发送失败。

### 3. **`xQueueSendFromISR()`**

**描述**：在中断服务例程（ISR）中向队列发送一个消息。

* **原型**：

  ```c
  BaseType_t xQueueSendFromISR(QueueHandle_t xQueue, const void *pvItemToQueue, BaseType_t *pxHigherPriorityTaskWoken);
  ```
* **参数**：

  * `xQueue`：队列句柄。
  * `pvItemToQueue`：指向待发送数据的指针。
  * `pxHigherPriorityTaskWoken`：指向一个布尔变量，如果从 ISR 中发送成功并且可能导致任务切换，设置为 `pdTRUE`，否则为 `pdFALSE`。
* **返回值**：

  * `pdPASS`：消息成功发送。

### 4. **`xQueueReceive()`**

**描述**：从队列接收一个消息（从队列的头部获取一个数据项）。

* **原型**：

  ```c
  BaseType_t xQueueReceive(QueueHandle_t xQueue, void *pvBuffer, TickType_t xTicksToWait);
  ```
* **参数**：

  * `xQueue`：队列句柄。
  * `pvBuffer`：指向存储接收到消息的缓冲区。
  * `xTicksToWait`：等待消息的时间（单位为 tick）。如果设置为 `0`，则不等待。
* **返回值**：

  * `pdPASS`：消息成功接收。
  * `errQUEUE_EMPTY`：队列为空，未能接收到消息。

### 5. **`xQueueReceiveFromISR()`**

**描述**：在中断服务例程（ISR）中从队列接收一个消息。

* **原型**：

  ```c
  BaseType_t xQueueReceiveFromISR(QueueHandle_t xQueue, void *pvBuffer, BaseType_t *pxHigherPriorityTaskWoken);
  ```
* **参数**：

  * `xQueue`：队列句柄。
  * `pvBuffer`：指向存储接收到消息的缓冲区。
  * `pxHigherPriorityTaskWoken`：指向一个布尔变量，如果接收成功并且可能导致任务切换，设置为 `pdTRUE`，否则为 `pdFALSE`。
* **返回值**：

  * `pdPASS`：消息成功接收。

### 6. **`xQueuePeek()`**

**描述**：查看队列的头部消息，但不将其从队列中移除。

* **原型**：

  ```c
  BaseType_t xQueuePeek(QueueHandle_t xQueue, void *pvBuffer, TickType_t xTicksToWait);
  ```
* **参数**：

  * `xQueue`：队列句柄。
  * `pvBuffer`：指向存储消息的缓冲区。
  * `xTicksToWait`：等待消息的时间（单位为 tick）。如果设置为 `0`，则不等待。
* **返回值**：

  * `pdPASS`：成功查看队列头部消息。
  * `errQUEUE_EMPTY`：队列为空，无法查看消息。

### 7. **`xQueuePeekFromISR()`**

**描述**：在中断服务例程（ISR）中查看队列头部消息，但不将其从队列中移除。

* **原型**：

  ```c
  BaseType_t xQueuePeekFromISR(QueueHandle_t xQueue, void *pvBuffer, BaseType_t *pxHigherPriorityTaskWoken);
  ```
* **参数**：

  * `xQueue`：队列句柄。
  * `pvBuffer`：指向存储消息的缓冲区。
  * `pxHigherPriorityTaskWoken`：指向一个布尔变量，表示是否有高优先级任务被唤醒。
* **返回值**：

  * `pdPASS`：成功查看队列头部消息。

### 8. **`xQueueReset()`**

**描述**：重置队列，将其清空并将所有队列项设置为无效状态。

* **原型**：

  ```c
  BaseType_t xQueueReset(QueueHandle_t xQueue);
  ```
* **参数**：

  * `xQueue`：队列句柄。
* **返回值**：

  * `pdPASS`：队列成功重置。

### 9. **`xQueueSendToBack()`**

**描述**：将一个消息添加到队列的尾部。

* **原型**：

  ```c
  BaseType_t xQueueSendToBack(QueueHandle_t xQueue, const void *pvItemToQueue, TickType_t xTicksToWait);
  ```
* **参数**：

  * `xQueue`：队列句柄。
  * `pvItemToQueue`：指向待发送数据的指针。
  * `xTicksToWait`：等待队列空位的时间（单位为 tick）。
* **返回值**：

  * `pdPASS`：消息成功发送。
  * `errQUEUE_FULL`：队列已满，消息发送失败。

### 10. **`xQueueSendToFront()`**

**描述**：将一个消息添加到队列的头部。

* **原型**：

  ```c
  BaseType_t xQueueSendToFront(QueueHandle_t xQueue, const void *pvItemToQueue, TickType_t xTicksToWait);
  ```
* **参数**：

  * `xQueue`：队列句柄。
  * `pvItemToQueue`：指向待发送数据的指针。
  * `xTicksToWait`：等待队列空位的时间（单位为 tick）。
* **返回值**：

  * `pdPASS`：消息成功发送。
  * `errQUEUE_FULL`：队列已满，消息发送失败。

### 11. **`xQueueSpacesAvailable()`**

**描述**：检查队列中可用的空间数。

* **原型**：

  ```c
  UBaseType_t xQueueSpacesAvailable(QueueHandle_t xQueue);
  ```
* **参数**：

  * `xQueue`：队列句柄。
* **返回值**：

  * 返回队列中剩余的可用空间（消息数）。

### 12. **`xQueueMessagesWaiting()`**

**描述**：检查队列中待处理的消息数。

* **原型**：

  ```c
  UBaseType_t xQueueMessagesWaiting(QueueHandle_t xQueue);
  ```
* **参数**：

  * `xQueue`：队列句柄。
* **返回值**：

  * 返回队列中当前等待处理的消息数。

---

### 总结

FreeRTOS 提供了一系列与消息队列相关的 API，主要包括：

* **创建和删除队列**：`xQueueCreate`
* **发送和接收消息**：`xQueueSend`, `xQueueReceive`
* **ISR 中使用的队列操作**：`xQueueSendFromISR`, `xQueueReceiveFromISR`
* **查看队列的头部消息**：`xQueuePeek`
* **队列管理**：`xQueueReset`, `xQueueSpacesAvailable`, `xQueueMessagesWaiting`

这些函数帮助任务之间高效地进行通信，并且支持中断服务例程（ISR）中进行队列操作，确保多任务和中断环境下的安全性与高效性。
