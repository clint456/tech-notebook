在 FreeRTOS 中，**信号量（Semaphore）** 是一种任务同步和资源共享的机制，用于控制任务间的协作。FreeRTOS 提供了多种类型的信号量，包括互斥信号量、二值信号量和计数信号量。以下是与信号量相关的所有函数以及它们的使用方法。

### 1. **`xSemaphoreCreateMutex()`**

**描述**：创建一个互斥信号量，用于任务间互斥访问共享资源。

- **原型**：

  ```c
  SemaphoreHandle_t xSemaphoreCreateMutex(void);
  ```

- **返回值**：

  - 成功：返回互斥信号量的句柄。
  - 失败：返回 `NULL`。

- **使用方法**：
   互斥信号量用于在多个任务间保证对共享资源的互斥访问。

  ```c
  SemaphoreHandle_t xMutex;
  xMutex = xSemaphoreCreateMutex();
  if (xMutex != NULL) {
      if (xSemaphoreTake(xMutex, portMAX_DELAY) == pdTRUE) {
          // 临界区代码
          xSemaphoreGive(xMutex);  // 释放互斥信号量
      }
  }
  ```

### 2. **`xSemaphoreCreateBinary()`**

**描述**：创建一个二值信号量，常用于任务间同步。

- **原型**：

  ```c
  SemaphoreHandle_t xSemaphoreCreateBinary(void);
  ```

- **返回值**：

  - 成功：返回二值信号量的句柄。
  - 失败：返回 `NULL`。

- **使用方法**：
   二值信号量通常用于同步任务或事件通知。它的值只有 `0` 或 `1`，可以用来指示事件的发生。

  ```c
  SemaphoreHandle_t xBinarySemaphore;
  xBinarySemaphore = xSemaphoreCreateBinary();
  if (xBinarySemaphore != NULL) {
      // 信号量释放
      xSemaphoreGive(xBinarySemaphore);
      // 信号量获取
      if (xSemaphoreTake(xBinarySemaphore, portMAX_DELAY) == pdTRUE) {
          // 处理接收到的信号
      }
  }
  ```

### 3. **`xSemaphoreCreateCounting()`**

**描述**：创建一个计数信号量，允许队列中有多个项。常用于限制某个资源的并发访问数目。

- **原型**：

  ```c
  SemaphoreHandle_t xSemaphoreCreateCounting(UBaseType_t uxMaxCount, UBaseType_t uxInitialCount);
  ```

- **参数**：

  - `uxMaxCount`：信号量的最大计数值。
  - `uxInitialCount`：信号量的初始计数值。

- **返回值**：

  - 成功：返回计数信号量的句柄。
  - 失败：返回 `NULL`。

- **使用方法**：
   计数信号量用于限制并发任务的数量，通常用于资源池、共享缓冲区等场景。

  ```c
  SemaphoreHandle_t xCountingSemaphore;
  xCountingSemaphore = xSemaphoreCreateCounting(5, 0);  // 最大5个，初始0
  if (xCountingSemaphore != NULL) {
      if (xSemaphoreTake(xCountingSemaphore, portMAX_DELAY) == pdTRUE) {
          // 获取到信号量
      }
      xSemaphoreGive(xCountingSemaphore);  // 释放信号量
  }
  ```

### 4. **`xSemaphoreTake()`**

**描述**：获取信号量，若信号量不可用，则阻塞直到信号量可用。

- **原型**：

  ```c
  BaseType_t xSemaphoreTake(SemaphoreHandle_t xSemaphore, TickType_t xTicksToWait);
  ```

- **参数**：

  - `xSemaphore`：信号量的句柄。
  - `xTicksToWait`：等待信号量的时间（以 tick 为单位）。如果设置为 `0`，则立即返回。

- **返回值**：

  - `pdTRUE`：成功获取信号量。
  - `pdFALSE`：获取信号量失败（例如，超时）。

- **使用方法**：
   任务获取信号量后才能访问共享资源，防止资源冲突。

  ```c
  if (xSemaphoreTake(xSemaphore, portMAX_DELAY) == pdTRUE) {
      // 获取到信号量，访问资源
  }
  ```

### 5. **`xSemaphoreGive()`**

**描述**：释放信号量，允许其他任务获取该信号量。

- **原型**：

  ```c
  BaseType_t xSemaphoreGive(SemaphoreHandle_t xSemaphore);
  ```

- **参数**：

  - `xSemaphore`：信号量的句柄。

- **返回值**：

  - `pdTRUE`：成功释放信号量。
  - `pdFALSE`：释放信号量失败（例如，信号量未被获取）。

- **使用方法**：
   在任务完成访问共享资源后，释放信号量以便其他任务可以访问该资源。

  ```c
  xSemaphoreGive(xSemaphore);
  ```

### 6. **`xSemaphoreTakeFromISR()`**

**描述**：在中断服务例程（ISR）中获取信号量。

- **原型**：

  ```c
  BaseType_t xSemaphoreTakeFromISR(SemaphoreHandle_t xSemaphore, BaseType_t *pxHigherPriorityTaskWoken);
  ```

- **参数**：

  - `xSemaphore`：信号量的句柄。
  - `pxHigherPriorityTaskWoken`：指向一个布尔变量，如果从 ISR 获取信号量成功并且可能导致任务切换，设置为 `pdTRUE`，否则为 `pdFALSE`。

- **返回值**：

  - `pdTRUE`：成功获取信号量。
  - `pdFALSE`：获取信号量失败。

- **使用方法**：
   在中断服务例程中使用 `xSemaphoreTakeFromISR` 来确保安全地从 ISR 中获取信号量。

  ```c
  BaseType_t xHigherPriorityTaskWoken = pdFALSE;
  if (xSemaphoreTakeFromISR(xSemaphore, &xHigherPriorityTaskWoken) == pdTRUE) {
      // 从 ISR 中成功获取信号量
  }
  ```

### 7. **`xSemaphoreGiveFromISR()`**

**描述**：在中断服务例程（ISR）中释放信号量。

- **原型**：

  ```c
  BaseType_t xSemaphoreGiveFromISR(SemaphoreHandle_t xSemaphore, BaseType_t *pxHigherPriorityTaskWoken);
  ```

- **参数**：

  - `xSemaphore`：信号量的句柄。
  - `pxHigherPriorityTaskWoken`：指向一个布尔变量，如果释放信号量后可能导致高优先级任务被唤醒，设置为 `pdTRUE`，否则为 `pdFALSE`。

- **返回值**：

  - `pdTRUE`：成功释放信号量。
  - `pdFALSE`：释放信号量失败。

- **使用方法**：
   在中断服务例程中释放信号量，并根据需要唤醒高优先级任务。

  ```c
  BaseType_t xHigherPriorityTaskWoken = pdFALSE;
  if (xSemaphoreGiveFromISR(xSemaphore, &xHigherPriorityTaskWoken) == pdTRUE) {
      // 从 ISR 中成功释放信号量
  }
  ```

### 8. **`xSemaphoreCreateRecursiveMutex()`**

**描述**：创建一个递归互斥信号量，用于支持同一任务在进入临界区时多次获取同一个互斥信号量。

- **原型**：

  ```c
  SemaphoreHandle_t xSemaphoreCreateRecursiveMutex(void);
  ```

- **返回值**：

  - 成功：返回递归互斥信号量的句柄。
  - 失败：返回 `NULL`。

- **使用方法**：
   递归互斥信号量允许同一个任务多次获取信号量，常用于任务调用嵌套的情景。

  ```c
  SemaphoreHandle_t xRecursiveMutex;
  xRecursiveMutex = xSemaphoreCreateRecursiveMutex();
  if (xRecursiveMutex != NULL) {
      if (xSemaphoreTakeRecursive(xRecursiveMutex, portMAX_DELAY) == pdTRUE) {
          // 访问共享资源
          xSemaphoreGiveRecursive(xRecursiveMutex);
      }
  }
  ```

### 9. **`xSemaphoreTakeRecursive()`**

**描述**：获取递归互斥信号量。

- **原型**：

  ```c
  BaseType_t xSemaphoreTakeRecursive(SemaphoreHandle_t xSemaphore, TickType_t xTicksToWait);
  ```

### 10. **`xSemaphoreGiveRecursive()`**

**描述**：释放递归互斥信号量。

- **原型**：

GiveRecursive(SemaphoreHandle_t xSemaphore);
 \```

### 总结

FreeRTOS 提供了丰富的信号量操作函数来满足不同的任务同步和资源管理需求。主要的函数包括：

- **创建信号量**：`xSemaphoreCreateMutex()`, `xSemaphoreCreateBinary()`, `xSemaphoreCreateCounting()`, `xSemaphoreCreateRecursiveMutex()`
- **获取信号量**：`xSemaphoreTake()`, `xSemaphoreTakeFromISR()`, `xSemaphoreTakeRecursive()`
- **释放信号量**：`xSemaphoreGive()`, `xSemaphoreGiveFromISR()`, `xSemaphoreGiveRecursive()`
- **信号量在 ISR 中使用**：`xSemaphoreTakeFromISR()`, `xSemaphoreGiveFromISR()`

这些函数可以根据具体的需求进行任务间的同步与资源保护，确保在嵌入式系统中高效且安全地管理任务与资源。
