在 FreeRTOS 中，**互斥量（Mutex）** 是一种用于保护共享资源的同步机制，确保同一时刻只有一个任务能够访问共享资源，从而避免多个任务同时访问资源时引发的数据冲突问题。互斥量不同于普通的信号量，主要用于任务间的互斥访问，特别是访问临界区代码时。

### 互斥量的特性

1. **任务同步**：互斥量用于保护共享资源，避免多个任务同时访问这些资源时引发数据竞争。
2. **递归互斥**：支持同一任务多次获取同一个互斥量，避免递归调用时的死锁问题。
3. **优先级继承**：在任务获得互斥量后，如果任务的优先级较低且阻塞了高优先级任务，系统会临时提高该任务的优先级，直到互斥量释放，从而避免优先级反转。

### 互斥量相关函数

FreeRTOS 提供了几种函数来创建、使用和管理互斥量。

### 1. **`xSemaphoreCreateMutex()`**

**描述**：创建一个普通互斥量。

- **原型**：

  ```c
  SemaphoreHandle_t xSemaphoreCreateMutex(void);
  ```

- **返回值**：

  - 成功：返回互斥量的句柄。
  - 失败：返回 `NULL`。

**使用示例**：

```c
SemaphoreHandle_t xMutex;
xMutex = xSemaphoreCreateMutex();
if (xMutex != NULL) {
    // 获取互斥量
    if (xSemaphoreTake(xMutex, portMAX_DELAY) == pdTRUE) {
        // 访问临界区资源
        // 释放互斥量
        xSemaphoreGive(xMutex);
    }
}
```

### 2. **`xSemaphoreCreateRecursiveMutex()`**

**描述**：创建一个递归互斥量，允许同一任务多次获取同一互斥量，适用于递归调用的场景。

- **原型**：

  ```c
  SemaphoreHandle_t xSemaphoreCreateRecursiveMutex(void);
  ```

- **返回值**：

  - 成功：返回递归互斥量的句柄。
  - 失败：返回 `NULL`。

**使用示例**：

```c
SemaphoreHandle_t xRecursiveMutex;
xRecursiveMutex = xSemaphoreCreateRecursiveMutex();
if (xRecursiveMutex != NULL) {
    // 获取递归互斥量
    if (xSemaphoreTakeRecursive(xRecursiveMutex, portMAX_DELAY) == pdTRUE) {
        // 访问临界区资源
        // 释放递归互斥量
        xSemaphoreGiveRecursive(xRecursiveMutex);
    }
}
```

### 3. **`xSemaphoreTake()`**

**描述**：获取互斥量，若互斥量被其他任务占用，则任务会阻塞，直到互斥量可用。

- **原型**：

  ```c
  BaseType_t xSemaphoreTake(SemaphoreHandle_t xSemaphore, TickType_t xTicksToWait);
  ```

- **参数**：

  - `xSemaphore`：互斥量的句柄。
  - `xTicksToWait`：等待互斥量的时间（以 tick 为单位）。如果设置为 `0`，则立即返回。

- **返回值**：

  - `pdTRUE`：成功获取互斥量。
  - `pdFALSE`：未能获取互斥量（例如，超时）。

- **使用示例**：

  ```c
  if (xSemaphoreTake(xMutex, portMAX_DELAY) == pdTRUE) {
      // 成功获取互斥量，访问资源
  }
  ```

### 4. **`xSemaphoreGive()`**

**描述**：释放互斥量，允许其他任务获取该互斥量。

- **原型**：

  ```c
  BaseType_t xSemaphoreGive(SemaphoreHandle_t xSemaphore);
  ```

- **参数**：

  - `xSemaphore`：互斥量的句柄。

- **返回值**：

  - `pdTRUE`：成功释放互斥量。
  - `pdFALSE`：未能释放互斥量（例如，互斥量未被当前任务持有）。

- **使用示例**：

  ```c
  xSemaphoreGive(xMutex);  // 释放互斥量
  ```

### 5. **`xSemaphoreTakeRecursive()`**

**描述**：获取递归互斥量。任务可以多次获取递归互斥量，而不会导致死锁。

- **原型**：

  ```c
  BaseType_t xSemaphoreTakeRecursive(SemaphoreHandle_t xSemaphore, TickType_t xTicksToWait);
  ```

- **参数**：

  - `xSemaphore`：递归互斥量的句柄。
  - `xTicksToWait`：等待互斥量的时间（以 tick 为单位）。

- **返回值**：

  - `pdTRUE`：成功获取递归互斥量。
  - `pdFALSE`：未能获取递归互斥量（例如，超时）。

- **使用示例**：

  ```c
  if (xSemaphoreTakeRecursive(xRecursiveMutex, portMAX_DELAY) == pdTRUE) {
      // 获取递归互斥量，访问资源
      xSemaphoreGiveRecursive(xRecursiveMutex);  // 释放递归互斥量
  }
  ```

### 6. **`xSemaphoreGiveRecursive()`**

**描述**：释放递归互斥量，允许其他任务获取该互斥量。

- **原型**：

  ```c
  BaseType_t xSemaphoreGiveRecursive(SemaphoreHandle_t xSemaphore);
  ```

- **参数**：

  - `xSemaphore`：递归互斥量的句柄。

- **返回值**：

  - `pdTRUE`：成功释放递归互斥量。
  - `pdFALSE`：未能释放递归互斥量。

- **使用示例**：

  ```c
  xSemaphoreGiveRecursive(xRecursiveMutex);  // 释放递归互斥量
  ```

### 7. **`xSemaphoreTakeFromISR()`**

**描述**：在中断服务例程（ISR）中获取互斥量。

- **原型**：

  ```c
  BaseType_t xSemaphoreTakeFromISR(SemaphoreHandle_t xSemaphore, BaseType_t *pxHigherPriorityTaskWoken);
  ```

- **参数**：

  - `xSemaphore`：互斥量的句柄。
  - `pxHigherPriorityTaskWoken`：指向一个布尔变量，若获取互斥量成功并且可能导致任务切换，设置为 `pdTRUE`，否则为 `pdFALSE`。

- **返回值**：

  - `pdTRUE`：成功获取互斥量。
  - `pdFALSE`：未能获取互斥量。

- **使用示例**：

  ```c
  BaseType_t xHigherPriorityTaskWoken = pdFALSE;
  if (xSemaphoreTakeFromISR(xMutex, &xHigherPriorityTaskWoken) == pdTRUE) {
      // 从ISR中成功获取互斥量
  }
  ```

### 8. **`xSemaphoreGiveFromISR()`**

**描述**：在中断服务例程（ISR）中释放互斥量。

- **原型**：

  ```c
  BaseType_t xSemaphoreGiveFromISR(SemaphoreHandle_t xSemaphore, BaseType_t *pxHigherPriorityTaskWoken);
  ```

- **参数**：

  - `xSemaphore`：互斥量的句柄。
  - `pxHigherPriorityTaskWoken`：指向一个布尔变量，若释放互斥量后可能导致高优先级任务被唤醒，设置为 `pdTRUE`，否则为 `pdFALSE`。

- **返回值**：

  - `pdTRUE`：成功释放互斥量。
  - `pdFALSE`：未能释放互斥量。

- **使用示例**：

  ```c
  BaseType_t xHigherPriorityTaskWoken = pdFALSE;
  if (xSemaphoreGiveFromISR(xMutex, &xHigherPriorityTaskWoken) == pdTRUE) {
      // 从ISR中成功释放互斥量
  }
  ```

### 总结

1. **普通互斥量**：适用于大多数任务间的同步。
