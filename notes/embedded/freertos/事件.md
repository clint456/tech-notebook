在 FreeRTOS 中，**事件标志组（Event Groups）** 是一种高效的任务间同步机制，通常用于在多个任务之间传递信号或标志。事件标志组允许多个任务在一个或多个标志位上进行同步，并可以有效地管理任务的事件和状态。

### 事件标志组的特性

1. **多标志位支持**：事件标志组允许多个标志位，任务可以设置、清除、等待多个标志位。
2. **位掩码操作**：每个事件标志都是一个二进制位，任务可以通过位掩码来设置、清除或等待特定的标志。
3. **任务同步**：事件标志组通常用于多个任务之间的同步，任务可以通过等待事件标志的方式阻塞，直到指定的事件发生。
4. **高效性**：事件标志组是基于位操作的，适合频繁的事件检测和高效的任务同步。

### 事件标志组的相关函数

以下是 FreeRTOS 中与事件标志组相关的主要函数：

### 1. **`xEventGroupCreate()`**

**描述**：创建一个事件标志组。

- **原型**：

  ```c
  EventGroupHandle_t xEventGroupCreate(void);
  ```

- **返回值**：

  - 成功：返回事件标志组的句柄。
  - 失败：返回 `NULL`。

- **使用示例**：

  ```c
  EventGroupHandle_t xEventGroup;
  xEventGroup = xEventGroupCreate();
  if (xEventGroup == NULL) {
      // 错误处理
  }
  ```

### 2. **`xEventGroupClearBits()`**

**描述**：清除事件标志组中的指定标志位。

- **原型**：

  ```c
  BaseType_t xEventGroupClearBits(EventGroupHandle_t xEventGroup, const EventBits_t uxBitsToClear);
  ```

- **参数**：

  - `xEventGroup`：事件标志组的句柄。
  - `uxBitsToClear`：需要清除的标志位的位掩码。

- **返回值**：

  - `pdPASS`：成功清除标志位。
  - `pdFAIL`：失败。

- **使用示例**：

  ```c
  xEventGroupClearBits(xEventGroup, 0x01);  // 清除事件标志位0
  ```

### 3. **`xEventGroupSetBits()`**

**描述**：设置事件标志组中的指定标志位。

- **原型**：

  ```c
  BaseType_t xEventGroupSetBits(EventGroupHandle_t xEventGroup, const EventBits_t uxBitsToSet);
  ```

- **参数**：

  - `xEventGroup`：事件标志组的句柄。
  - `uxBitsToSet`：需要设置的标志位的位掩码。

- **返回值**：

  - `pdPASS`：成功设置标志位。
  - `pdFAIL`：失败。

- **使用示例**：

  ```c
  xEventGroupSetBits(xEventGroup, 0x01);  // 设置事件标志位0
  ```

### 4. **`xEventGroupWaitBits()`**

**描述**：等待事件标志组中的某些标志位被设置。该函数会阻塞当前任务，直到满足指定的标志位条件。

- **原型**：

  ```c
  EventBits_t xEventGroupWaitBits(EventGroupHandle_t xEventGroup, const EventBits_t uxBitsToWaitFor,
                                   const BaseType_t xClearOnExit, const BaseType_t xWaitForAllBits,
                                   TickType_t xTicksToWait);
  ```

- **参数**：

  - `xEventGroup`：事件标志组的句柄。
  - `uxBitsToWaitFor`：等待的标志位的位掩码。
  - `xClearOnExit`：当等待的标志位被设置后，是否清除它们。
  - `xWaitForAllBits`：是否等待所有指定标志位被设置。
  - `xTicksToWait`：等待的时间（以 tick 为单位）。

- **返回值**：

  - 返回当前事件标志组的状态（包括已经设置的标志位）。

- **使用示例**：

  ```c
  EventBits_t uxBits;
  uxBits = xEventGroupWaitBits(xEventGroup, 0x01, pdTRUE, pdFALSE, portMAX_DELAY);
  if (uxBits & 0x01) {
      // 事件标志位0已被设置，执行相应的操作
  }
  ```

### 5. **`xEventGroupClearBitsFromISR()`**

**描述**：在中断服务例程（ISR）中清除事件标志位。

- **原型**：

  ```c
  BaseType_t xEventGroupClearBitsFromISR(EventGroupHandle_t xEventGroup, const EventBits_t uxBitsToClear);
  ```

- **参数**：

  - `xEventGroup`：事件标志组的句柄。
  - `uxBitsToClear`：需要清除的标志位的位掩码。

- **返回值**：

  - `pdPASS`：成功清除标志位。
  - `pdFAIL`：失败。

- **使用示例**：

  ```c
  xEventGroupClearBitsFromISR(xEventGroup, 0x01);  // 清除事件标志位0
  ```

### 6. **`xEventGroupSetBitsFromISR()`**

**描述**：在中断服务例程（ISR）中设置事件标志位。

- **原型**：

  ```c
  BaseType_t xEventGroupSetBitsFromISR(EventGroupHandle_t xEventGroup, const EventBits_t uxBitsToSet, BaseType_t *pxHigherPriorityTaskWoken);
  ```

- **参数**：

  - `xEventGroup`：事件标志组的句柄。
  - `uxBitsToSet`：需要设置的标志位的位掩码。
  - `pxHigherPriorityTaskWoken`：指向一个布尔值，若设置标志位后可以导致高优先级任务的切换，则为 `pdTRUE`，否则为 `pdFALSE`。

- **返回值**：

  - `pdPASS`：成功设置标志位。
  - `pdFAIL`：失败。

- **使用示例**：

  ```c
  BaseType_t xHigherPriorityTaskWoken = pdFALSE;
  xEventGroupSetBitsFromISR(xEventGroup, 0x01, &xHigherPriorityTaskWoken);
  ```

### 7. **`xEventGroupWaitBitsFromISR()`**

**描述**：在中断服务例程（ISR）中等待事件标志位。此函数会返回当前标志组的状态，并且不会阻塞任务。

- **原型**：

  ```c
  EventBits_t xEventGroupWaitBitsFromISR(EventGroupHandle_t xEventGroup, const EventBits_t uxBitsToWaitFor,
                                          const BaseType_t xClearOnExit, const BaseType_t xWaitForAllBits);
  ```

- **参数**：

  - `xEventGroup`：事件标志组的句柄。
  - `uxBitsToWaitFor`：等待的标志位的位掩码。
  - `xClearOnExit`：是否在退出时清除已设置的标志位。
  - `xWaitForAllBits`：是否等待所有指定标志位被设置。

- **返回值**：

  - 返回当前事件标志组的状态。

- **使用示例**：

  ```c
  EventBits_t uxBits;
  uxBits = xEventGroupWaitBitsFromISR(xEventGroup, 0x01, pdTRUE, pdFALSE);
  ```

------

### 总结

在 FreeRTOS 中，事件标志组是一种灵活且高效的任务同步机制，适用于任务间的信号传递和状态管理。常见的事件标志组操作包括：

- **创建事件标志组**：`xEventGroupCreate()`
- **设置标志位**：`xEventGroupSetBits()`
- **清除标志位**：`xEventGroupClearBits()`
- **等待标志位**：`xEventGroupWaitBits()`
- **ISR 中操作事件标志组**：`xEventGroupSetBitsFromISR()`, `xEventGroupClearBitsFromISR()`

事件标志组通过位操作，允许任务等待、设置和清除多个事件标志，为任务同步提供了一种简单、灵活且高效的方式。
