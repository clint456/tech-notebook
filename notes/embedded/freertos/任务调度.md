# 任务管理

FreeRTOS 提供了一系列的任务管理函数，用于创建、控制、删除和调度任务。以下是任务管理的主要 API 函数及其作用：

### 1. **`xTaskCreate()`**

**描述**：创建一个新的任务。

- **原型**：

  ```c
  BaseType_t xTaskCreate(TaskFunction_t pvTaskCode,
                          const char * const pcName,
                          configSTACK_DEPTH_TYPE usStackDepth,
                          void * pvParameters,
                          UBaseType_t uxPriority,
                          TaskHandle_t * pxCreatedTask);
  ```

- **用途**：用于创建一个新的任务并将其加入任务调度队列。

### 2. **`vTaskDelete()`**

**描述**：删除指定任务，释放其占用的资源。

- **原型**：

  ```c
  void vTaskDelete(TaskHandle_t xTaskToDelete);
  ```

- **用途**：删除一个任务，若传递 `NULL`，则删除当前任务。

### 3. **`vTaskDelay()`**

**描述**：使任务延迟一段时间。

- **原型**：

  ```c
  void vTaskDelay(const TickType_t xTicksToDelay);
  ```

- **用途**：延迟指定 tick 数（即系统时钟周期），让当前任务阻塞，等待下一次调度。

### 4. **`vTaskDelayUntil()`**

**描述**：使任务延迟直到某个指定的时间点。

- **原型**：

  ```c
  void vTaskDelayUntil(TickType_t *pxPreviousWakeTime, const TickType_t xTimeIncrement);
  ```

- **用途**：延迟直到指定的时间点，通常用于周期性任务，确保任务周期固定。

### 5. **`vTaskSuspend()`**

**描述**：挂起指定任务。

- **原型**：

  ```c
  void vTaskSuspend(TaskHandle_t xTaskToSuspend);
  ```

- **用途**：挂起一个任务，挂起的任务不会参与调度，直到显式恢复。

### 6. **`vTaskResume()`**

**描述**：恢复挂起的任务。

- **原型**：

  ```c
  void vTaskResume(TaskHandle_t xTaskToResume);
  ```

- **用途**：恢复被挂起的任务，使其能够再次参与调度。

### 7. **`vTaskPrioritySet()`**

**描述**：设置任务的优先级。

- **原型**：

  ```c
  void vTaskPrioritySet(TaskHandle_t xTask, UBaseType_t uxNewPriority);
  ```

- **用途**：动态改变任务的优先级。

### 8. **`xTaskPriorityGet()`**

**描述**：获取任务的当前优先级。

- **原型**：

  ```c
  UBaseType_t xTaskPriorityGet(TaskHandle_t xTask);
  ```

- **用途**：获取指定任务的当前优先级。若传递 `NULL`，则返回当前任务的优先级。

### 9. **`xTaskGetTickCount()`**

**描述**：获取系统自启动以来的 tick 数。

- **原型**：

  ```c
  TickType_t xTaskGetTickCount(void);
  ```

- **用途**：返回从系统启动开始的 tick 数。常用于计算时间间隔。

### 10. **`xTaskGetCurrentTaskHandle()`**

**描述**：获取当前任务的句柄。

- **原型**：

  ```c
  TaskHandle_t xTaskGetCurrentTaskHandle(void);
  ```

- **用途**：获取当前正在执行任务的句柄。

### 11. **`xTaskGetIdleTaskHandle()`**

**描述**：获取空闲任务的句柄。

- **原型**：

  ```c
  TaskHandle_t xTaskGetIdleTaskHandle(void);
  ```

- **用途**：获取空闲任务的句柄，通常用于在需要时挂起空闲任务。

### 12. **`xTaskGetSchedulerState()`**

**描述**：获取调度器的状态。

- **原型**：

  ```c
  BaseType_t xTaskGetSchedulerState(void);
  ```

- **用途**：返回调度器的状态。可以用来判断是否正在调度任务。

### 13. **`xTaskResumeAll()`**

**描述**：恢复所有挂起的任务。

- **原型**：

  ```c
  BaseType_t xTaskResumeAll(void);
  ```

- **用途**：恢复所有挂起的任务，并重新启动调度器。

### 14. **`vTaskStartScheduler()`**

**描述**：启动 FreeRTOS 调度器。

- **原型**：

  ```c
  BaseType_t vTaskStartScheduler(void);
  ```

- **用途**：启动任务调度器，让 FreeRTOS 开始执行任务。

### 15. **`xTaskAbortDelay()`**

**描述**：终止任务的延迟。

- **原型**：

  ```c
  BaseType_t xTaskAbortDelay(TaskHandle_t xTask);
  ```

- **用途**：中止任务的延迟，使任务尽快恢复执行。

### 16. **`xTaskResumeAll()`**

**描述**：恢复所有挂起的任务。

- **原型**：

  ```c
  BaseType_t xTaskResumeAll(void);
  ```

- **用途**：恢复所有任务并重新启动调度器。

### 17. **`xTaskGetHandle()`**

**描述**：通过任务名称获取任务句柄。

- **原型**：

  ```c
  TaskHandle_t xTaskGetHandle(const char *pcName);
  ```

- **用途**：通过任务名称获取任务句柄，用于对任务进行后续操作。

### 18. **`xTaskGetTaskName()`**

**描述**：获取任务的名称。

- **原型**：

  ```c
  const char * xTaskGetTaskName(TaskHandle_t xTask);
  ```

- **用途**：获取指定任务的名称。若任务为 `NULL`，则获取当前任务名称。

### 19. **`xTaskCallApplicationTaskHook()`**

**描述**：调用任务钩子函数（如果有的话）。

- **原型**：

  ```c
  void xTaskCallApplicationTaskHook(TaskHandle_t xTask);
  ```

- **用途**：可以在任务执行前后调用应用程序定义的钩子函数。

### 20. **`vTaskSetApplicationTaskTag()`**

**描述**：为任务设置应用程序任务标签。

- **原型**：

  ```c
  void vTaskSetApplicationTaskTag(TaskHandle_t xTask, void *pvTag);
  ```

- **用途**：为任务设置一个用户定义的标签，通常用于调试或任务跟踪。

### 21. **`xTaskGetApplicationTaskTag()`**

**描述**：获取任务的应用程序任务标签。

- **原型**：

  ```c
  void *xTaskGetApplicationTaskTag(TaskHandle_t xTask);
  ```

- **用途**：获取任务的应用程序标签。

------

### 总结

FreeRTOS 提供了很多任务管理的 API 来创建、控制、延迟、挂起、恢复和删除任务。以下是这些 API 的主要功能：

- **创建与删除任务**：`xTaskCreate`, `vTaskDelete`
- **任务延迟与周期性调度**：`vTaskDelay`, `vTaskDelayUntil`
- **任务挂起与恢复**：`vTaskSuspend`, `vTaskResume`
- **任务优先级管理**：`vTaskPrioritySet`, `xTaskPriorityGet`
- **任务状态与调度器控制**：`xTaskGetSchedulerState`, `xTaskGetTickCount`
- **任务信息获取**：`xTaskGetCurrentTaskHandle`, `xTaskGetHandle`

这些任务管理函数为 FreeRTOS 提供了强大的任务控制能力，允许开发者根据需求灵活地管理任务的生命周期、优先级和调度行为。
