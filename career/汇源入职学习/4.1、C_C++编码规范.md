<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">※</font><font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">有时候加个后缀是很有用的。比如类是一个代理</font><font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">(Agents)</font><font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">时，起名叫</font><font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">DownloadAgent</font><font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">更能表达真实的意图。</font><font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">※</font>

<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">Cnt – 表示当前的</font><font style="color:rgb(0,0,0);background-color:#FBDE28;">计数值</font>

<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">Key – </font><font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">表示键值</font>

<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">※</font><font style="color:rgb(0,0,0);background-color:#FBDE28;">前缀</font><font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">也同样有用：</font>

<font style="color:rgb(0,0,0);background-color:#FBDE28;">Is</font><font style="color:rgb(0,0,0);background-color:rgb(255,255,255);"> – 用于询问一些问题。只要看到Is开头，就知道这是一个查询。</font>

<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">Get – </font><font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">用于获取一个值。</font>

<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">Set – </font><font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">用于设置一个值。</font>

<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">例如：</font><font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">IsHitRetryLimit.</font>

> + **Is **: 表示这是一个布尔值（`**true**` 或 `**false**`）的判断，通常用于描述某种状态或条件是否成立。
> + **Hit **: 在这里可以理解为“达到”或“触发”的意思，表示某个事件或条件已经被满足。
> + **Retry **: 意为“重试”，通常与某种尝试操作相关，比如网络请求失败后重新尝试。
> + **Limit **: 表示“限制”或“上限”，通常指某个数值的最大值。
> + **“是否已经达到了重试的限制次数”**
>

### **<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">1.1.3.</font>****<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">含有度量单位的名称（适用于</font>****<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">C/C++</font>****<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">）</font>**
<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">※</font><font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">如果一个变量用于表示时间，重量或其它度量单位，应把度量单位添加到名称中，以便开发人员更早一步发现问题。</font>

<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">例如：</font>

<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">uint32 mTimeoutMsecs;</font>

> + m : 在许多编程语言中（尤其是 C++、Java 等），m 通常是 "member" 的缩写，表示这是一个类的成员变量（member variable）。这是一种常见的命名约定，用于区分成员变量和局部变量。
> + Timeout : 意为“超时”，表示某个操作在指定时间内未完成时触发的事件或状态。
> + Msecs : 是 "milliseconds" 的缩写，表示“毫秒”。它明确了时间单位。
> + “以毫秒为单位的超时时间（作为类的成员变量）”
>

<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">uint32 mMyWeightLbs;</font>

> + <font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">Lbs：明确了重量的单位是“磅”。</font>
>

## **<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">1.2.</font>****<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">类的命名（适用于</font>****<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">C++</font>****<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">）</font>**
<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">※</font><font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">用大写字母作为单词的分隔，每个单词的首字母大写，其它字母均小写。</font>

<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">※</font><font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">名字的第一个字母应大写</font>

## **<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">1.3.</font>****<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">类库（或程序库）命名 （适用于</font>****<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">C/C++</font>****<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">）</font>**
<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">※</font><font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">使用命名空间防止名字冲突。</font>


C++ 中指针声明的语法有时会让人困惑，尤其是当多个变量声明在同一行时。例如：

在这里，* 只作用于 pName，而 name 是一个普通的 String 对象。这与直觉可能不符，因为有些人会误以为 * 作用于整个声明行。

为了避免这种误解，更好的做法是：

将每个变量单独声明。

```cpp
String *pName;
```

```cpp
extern “C” int some_bloody_function();
```

##### extern "C" 解释:
`extern "C" int some_bloody_function();` 是一个函数声明，结合了 C++ 和 C 的特性。它的主要目的是在 C++ 程序中调用 C 风格的函数，避免因 C++ 的名称修饰（name mangling）而导致链接错误。以下是对该声明的详细分析和解释。

---

###### 1. 背景：C++ 名称修饰（Name Mangling）
在 C++ 中，编译器会对函数名进行修饰（name mangling），以便支持函数重载、命名空间等特性。例如，以下两个函数：

```cpp
void foo(int);
void foo(double);
```

在编译后可能会被修饰为类似 `_Z3fooi` 和 `_Z3food` 的符号，以区分它们的参数类型。

然而，C 语言不支持这些特性，因此 C 编译器不会对函数名进行修饰。如果直接在 C++ 中调用 C 函数，可能会因为名称修饰的不同而导致链接失败。

---

###### 2. `extern "C"` 的作用
`extern "C"` 告诉 C++ 编译器以 C 的方式处理函数声明，禁用名称修饰。这样可以确保 C++ 程序能够正确调用 C 函数。

(1) 语法

```cpp
extern "C" 返回值类型 函数名(参数列表);
```

(2) 效果

+ 禁用名称修饰。
+ 允许 C++ 程序与 C 库或 C 风格的代码交互。

---

###### 3. 具体分析：`extern "C" int some_bloody_function();`
(1) 含义

+ `extern "C"`：告诉编译器以 C 的方式处理 `some_bloody_function`。
+ `int`：函数返回值类型为 `int`。
+ `some_bloody_function()`：函数名为 `some_bloody_function`，无参数。

(2) 用途 

+ 这个声明通常用于在 C++ 程序中调用一个用 C 编写的函数。
+ 它确保 C++ 编译器不会对 `some_bloody_function` 的名称进行修饰，从而可以正确链接到 C 库中的实现。

---

###### 4. 实际应用场景
(1) 调用 C 库

假设有一个 C 库 `libexample.so`，其中定义了一个函数：

```c
// example.c
int some_bloody_function() {
    return 42;
}
```

在 C++ 程序中调用这个函数时，需要使用 `extern "C"`：

```cpp
// main.cpp
extern "C" int some_bloody_function();

int main() {
    int result = some_bloody_function();
    std::cout << "Result: " << result << std::endl;
    return 0;
}
```

(2) 或者使用预处理在头文件中的声明

为了方便使用，通常会在头文件中使用 `extern "C"` 包裹整个声明部分：

```c
// example.h
#ifdef __cplusplus
extern "C" {
#endif

int some_bloody_function();

#ifdef __cplusplus
}
#endif
//“根据编译器类型（C 或 C++），有条件地启用 extern "C"，以确保代码在两种语言中都能正确编译和链接”
```

+ `__cplusplus` 是一个预定义宏，仅在 C++ 编译器中定义。
+ 如果是 C++ 编译器，则启用 `extern "C"`；如果是 C 编译器，则忽略 `extern "C"`。

---

###### 5. 总结
`extern "C" int some_bloody_function();` 的含义是：  
**“这是一个 C 风格的函数声明，C++ 编译器应以 C 的方式处理它，禁用名称修饰。”**

这种声明主要用于以下场景：

1. 在 C++ 程序中调用 C 函数。
2. 编写跨语言兼容的动态库接口。
3. 确保 C++ 和 C 代码之间的互操作性。

通过使用 `extern "C"`，可以避免因名称修饰导致的链接问题，同时保持代码的可移植性和兼容性。

#### <font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">3. </font>前置声明（引用）
```cpp

```

+ <font style="color:rgb(25, 27, 31);">前置声明（Forward Declaration）是C++中的一种技术，用于在声明某个实体（通常是类、函数、变量等）的名称而无需提供其详细定义。</font>
+ <font style="color:rgb(25, 27, 31);">前置声明的目的是为了告诉编译器某个实体的存在，以便在稍后的代码中引用它，而不必在声明的地方提供完整的定义。</font>
+ <font style="color:rgb(25, 27, 31);">这可以提高编译速度和减少编译依赖性。</font>
+ <font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">例如：</font>

```cpp
class AnotherClass; // 前置引用
```

+ **优点**<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">：</font>
    - <font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">减少头文件的依赖，加快编译速度。</font>
    - <font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">避免循环依赖问题。</font>

## **<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">2.4. </font>****<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">保证一行只写一条语句 （适用于</font>****<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">C/C++</font>****<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">）</font>**
<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">※</font><font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">一行最多只写一条语句</font>

<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">※</font><font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">一行只定义一个变量</font>

<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">char** a, *x;</font>

<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">int width, height; //widthand height of image</font>

<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">要象这样</font><font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">:</font>

## **<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">2.5. </font>****<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">花括号 </font>****<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">{} </font>****<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">规则 （适用于</font>****<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">C/C++</font>****<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">）</font>**
### **<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">2.5.1.</font>****<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">花括号的位置</font>**
<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">※</font><font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">在关键字的下一行单独放置括号，并且与关键字对齐，如：</font>

<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">if (condition)       </font>

<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">{</font>

<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">...</font>

<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">}</font>

<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">while (condition)</font>

<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">{</font>

<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">…</font>

<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">}</font>

### **<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">2.5.2. </font>****<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">什么时候应使用花括号</font>**
<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">所有的</font><font style="color:rgb(0,0,0);background-color:rgb(255,255,255);"> if, while </font><font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">和 </font><font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">do </font><font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">语句，要么用单行格式，要么使用花括号格式。</font>

<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">※</font><font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">使用花括号格式：</font>

<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">if (1 == somevalue)</font>

<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">{</font>

<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">somevalue = 2;</font>

<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">}</font>

```cpp
// 错误写法：意外赋值
if (somevalue = 1) { // 编译器不会报错，但逻辑错误
    // ...
}

// 正确写法：Yoda 条件
if (1 = somevalue) { // 编译器会报错，提示无法对常量赋值
    // ...
}
```

<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">※</font><font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">单行格式：</font>

<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">if (1 == somevalue) somevalue = 2;</font>

<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">或下面这样（对于这种写法，建议使用花括号）：</font>

<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">if (1 == somevalue)</font>

<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">{</font><font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">  
</font><font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">somevalue = 2;</font>

<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">}</font>

### **<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">2.5.3.</font>****<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">在花括号结束的位置加上注释</font>**
<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">※</font><font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">在花括号结束的位置加上注释是一个好习惯。假如前后花括号距离很远，注释就能帮你理解它是如何对应的。如：</font>

<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">while(1)</font>

<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">{</font>

<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">if (valid)</font>

<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">{</font>

<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);"></font>

<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">} // if valid</font>

<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">else</font>

<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">{</font>

<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">} // not valid</font>

<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);"></font>

<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">} // end forever</font>

### **<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">2.5.4.</font>****<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">注意屏幕大小</font>**
<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">※</font><font style="color:rgb(0,0,0);background-color:#FBDE28;">一个语句块尽量不超过一个屏幕大小</font><font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">，这样，不要卷动屏幕就可以阅读代码。</font>

<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">※</font><font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">圆括号与函数名之间不要有空格。</font>

<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">※</font><font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">Return </font><font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">语句不要使用圆括号。</font>

<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">}</font>

<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);"></font>

<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">strcpy(s, s1);</font>

<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">return 1;</font>

## **<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">2.9. </font>****<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">使用</font>****<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">goto,continue,break </font>****<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">和 </font>****<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">?: </font>****<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">（适用于</font>****<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">C/C++</font>****<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">）</font>**
### **<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">2.9.1.</font>****<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);"> </font>****<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">g</font>****<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">oto</font>**
<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">※</font><font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">尽量避免使用</font><font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">g</font><font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">oto </font><font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">语句。一个合理使用</font><font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">goto</font><font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">语句的场合是，当你需要从多层循环中跳出。例如：</font>

<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">for (...)</font>

<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">{</font>

<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">while (...)</font>

<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">{</font>

<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">...</font>

<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">if (disaster)</font>

<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">goto error; //</font><font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">跳出循环</font>

<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">}</font>

<font style="color:rgb(0,0,0);background-color:rgb(255,255,255);">}</font>

# 3. 文档及注释
为了提高代码的可读性和可维护性，应使用文档自动生成工具（如 Doxygen）生成程序文档。以下是对 C/C++ 项目中注释规范的详细说明。

---

## 3.1 文件或程序库的文档注释
为整个文件编写文档，描述其功能、用途和相关背景信息。

#### 示例：
```cpp
/// @brief 简要描述文件的功能。
/// 描述可以继续。
///
/// 详细描述从这里开始。
/// 可以包括文件的用途、模块关系等。
```

---

## 3.2 类文档注释
在类定义前添加类说明文档，描述类的功能、作者、版本、日期、已知问题等。

#### 示例：
```cpp
/// WindowsNT
/// @brief 简要描述类的功能。
/// @author Bill Gates
/// @author Several species of small furry animals gathered together
///         in a cave and grooving with a pict.
/// @version 4.0
/// @date 1996-1998
/// @bug 它经常崩溃，并且需要大量内存。
/// @bug 该类使用时间越长，引入的 bug 越多。
/// @warning 该类可能会在你面前爆炸。
/// @warning 如果你继承了这个类，你注定会失败。
class WindowsNT {};
```

---

## 3.3 类成员变量注释
对类的成员变量进行注释，可以选择在变量上方或后方添加注释。

#### (1) 在成员变量上方加注释：
```cpp
/// 成员变量描述
int m_Var;
```

#### (2) 在成员变量后方加注释（<font style="background-color:#FBDE28;">需加 </font>`<font style="background-color:#FBDE28;"><</font>`<font style="background-color:#FBDE28;"> 符号</font>）：
```cpp
int m_color; ///< 颜色变量
```

---

### **3.4 函数文档注释**
为函数编写详细的文档注释，包括<font style="background-color:#FBDE28;">参数、返回值、异常、前提条件、警告、备注</font>等。

#### 示例：
```cpp
/// 赋值操作符
/// @param val 将要赋给本对象的值
/// @return 本对象的引用
XX& operator=(XX& val);
```

#### 常用属性说明：
1. **前提条件 (pre)**  
定义调用函数的前提条件。

```cpp
/// @pre
///     - 需要保证 (from != 0)
///     - 需要保证 (to != 0)
```

2. **警告说明 (warning)**  
定义一些关于函数必须知道的事情。

```cpp
/// @warning
/// 缓冲区必需足够大，以便容纳要拷贝的字串。
```

3. **备注说明 (remarks)**  
提供一些额外的备注信息。

```cpp
/// @remarks
/// 该函数不支持多线程环境。
```

4. **将要完成的工作 (todo)**  
说明未来需要完成的任务。

```cpp
/// @todo
/// 实现对 Unicode 字符的支持。
```

5. **使用例子说明 (example)**  
提供一个示例文件或代码片段。

```cpp
/// @example teststrcpy.cpp
```

#### 综合示例：
```cpp
/// 复制一个字串
///
/// @pre
///     - 需要保证 (from != 0)
///     - 需要保证 (to != 0)
///
/// @warning
/// 缓冲区必需足够大，以便容纳要拷贝的字串。
///
/// @example teststrcpy.cpp
///
/// @param from 要拷贝的字串
/// @param to 用于容纳字串的缓冲区
/// @return void
void strcpy(const char* from, char* to);
```

---

### **3.5 Include 语句注释**
如果有必要，对 `#include` 语句添加注释，说明包含该头文件的原因。

#### 示例：
```cpp
#include <iostream> // 包含标准输入输出流
#include "project_utils.h" // 包含项目公共工具函数
```

---

### **3.6 语句块注释**
为语句块添加注释，可以在语句块的开头和结束位置添加注释，描述其功能。

#### 示例：
```cpp
{
    // Block1 (Block1 的功能描述)
    ... some code

    {
        // Block2 (Block2 的功能描述)
        ... some code
    } // End Block2
} // End Block1
```

---

### **总结**
通过遵循上述注释规范，可以确保代码具有良好的文档化特性，便于团队协作和后续维护。以下是关键点总结：

1. **文件注释**：描述文件的整体功能和背景。
2. **类注释**：描述类的功能、作者、版本、日期、已知问题等。
3. **成员变量注释**：在变量上方或后方添加注释，解释其用途。
4. **函数注释**：详细描述函数的参数、返回值、前提条件、警告、备注等。
5. **Include 注释**：说明包含头文件的原因。
6. **语句块注释**：为嵌套的语句块添加注释，明确其功能。

这些规范不仅有助于生成高质量的自动文档，还能显著提升代码的可读性和可维护性。

# 4. 编码要求
## 4.1 不要忽略编译器警告
+ **原因**：编译器警告通常能指出代码中的笔误或潜在的逻辑错误。
+ **做法**：确保代码在编译时不会产生任何警告信息。如果出现警告，应立即修复。

---

## 4.2 使用源代码管理工具
+ **原因**：源代码管理工具（如 Git、SVN）对于团队协作和代码版本控制至关重要。
+ **做法**：
    - 根据项目规模选择合适的工具。
    - 定期提交代码并添加有意义的提交信息。

---

## 4.3 固有的类方法成员
### (1) 默认构造函数
+ 如果所有参数都是可选的，则该构造函数也是默认构造函数。
+ 如果未定义任何构造函数，编译器会自动生成一个默认构造函数。

### (2) 虚析构函数
+ 如果一个类可能<font style="color:#DF2A3F;">被继承，则应定义虚析构函数</font>。
+ 如果未定义虚析构函数，编译器会生成一个非虚析构函数，可能导致资源泄漏。

### (3) 拷贝构造函数
+ 如果一个类<font style="color:#DF2A3F;">不应被拷贝</font>，<font style="color:#DF2A3F;">应定义私有的拷贝构造函数且不实现</font>。
+ 如果不确定是否需要拷贝，优先假设不可拷贝。

### (4) 赋值操作符
+ 如果一个<font style="color:#DF2A3F;">类不应被赋值，应定义私有的赋值操作符且不实现</font>。
+ 如果<font style="color:#DF2A3F;">不确定是否需要赋值，优先假设不可赋值</font>。

---

### **4.4 使用命名空间**
#### (1) **命名规则**
+ 根命名空间通常是公司名、项目名或模块名。
+ 示例：

```cpp
namespace CompanyName {
namespace ProjectName {
    class MyClass {};
} // namespace ProjectName
} // namespace CompanyName
```

#### (2) **避免全局 **`using`** 语句**
+ <font style="color:#DF2A3F;">不要在头文件或全局作用域中使用 </font>`<font style="color:#DF2A3F;">using namespace std;</font>` 或类似语句，以免污染全局命名空间。
+ 示例：

```cpp
// 错误
using namespace std;

// 正确
std::string myString;
```

---

### **4.5 初始化所有变量**
+ **原因**：未初始化的变量可能导致未定义行为。
+ **做法**：<font style="color:#DF2A3F;">始终显式初始化所有变量。</font>

```cpp
int x = 0;        // 显式初始化
bool flag = false; // 显式初始化
```

---

### **4.6 保持函数短小精悍**
+ **原则**：<font style="color:#DF2A3F;">一个函数应在 1-3 屏内完成其功能。</font>
+ **做法**：
    - 如果函数过长，考虑将其拆分为多个小函数。
    - <font style="color:#DF2A3F;">每个函数应专注于完成单一任务。</font>

---

### **4.7 对空语句进行注释**
※For和while语句如果跟随一个空语句，需要对此语句进行注释，并且空语句应另起一行。如：

   while(*dest++ = *src++)

      ;         // void

※不允许写成：

   while (*dest++ = *src++) ;   // 绝对不允许这么写

```cpp
while (*dest++ = *src++)
    ; // void 注释内容
```

---

### **4.8 避免用 **`if`** 语句的默认方法测试非零值**
+ **原因**：直接测试非零值可能导致逻辑错误。
+ **做法**：
    - 使用显式的布尔比较。
    - 示例：

```cpp
#define FAIL true
// 推荐
if (FAIL != f()) { ... }

// 不推荐
if (f()) { ... }
```

#### 宏定义与内联函数
+ 使用宏或内联函数代替复杂的表达式。
+ 示例：

```cpp
#define STREQ(a, b) (strcmp((a), (b)) == 0)

inline bool StringEqual(const char* a, const char* b) {
    return strcmp(a, b) == 0;
}
```

---

### **4.9 布尔类型**
+ **原因**：现代 C++ 提供了内置的布尔类型 `bool`。
+ **做法**：
    - 使用 `bool` 类型代替整数表示布尔值。
    - 示例：

```cpp
bool isValid = true;
if (!isValid) { ... }
```

#### 早期布尔类型的替代
+ <font style="color:#DF2A3F;">如果必须使用整数表示布尔值，建议如下：</font>

```cpp
const int TRUE = 1;
const int FALSE = 0;

if (FALSE != func()) { ... }
```

---

### **4.10 避免在语句中内含赋值**
+ **原因**：内含赋值可能导致代码难以理解或引入副作用。
+ **做法**：
    - 只有在明确提高可读性时才允许内含赋值。
    - 示例：

```cpp
// 允许
while (EOF != (c = getchar())) {
    process_character(c);
}

// 不推荐
d = (a = b + c) + r;
```

---

### **4.11 正确使用 **`const`
+ **原因**：`const` 可以提高代码的安全性和可读性。
+ **做法**：
    - 使用 `const` 修饰不会被修改的对象或数据。
    - 示例：

```cpp
const int MAX_VALUE = 100;
const std::string& getName() const;
```

---

### **4.12 不要在头文件中定义数据**
+ **原因**：头文件中的数据定义会导致多重定义问题。
+ **做法**：
    - 在头文件中声明外部变量。
    - 在对应的 `.cpp` 文件中定义变量。
    - 示例：

```cpp
//不要把数据定义放在头文件，如：
/*
 * aheader.h
 */
int x = 0;


//而应该在对应的c或cpp文件中定义，如：
/*
 * aheader.c
 */
int x = 0;
而在头文件中这样写：
/*
 * aheader.h
 */
extern int x;
```

---

### **4.13 不要直接使用数字**
+ **原因**：直接使用数字（魔术数字）会使代码难以理解和维护。
+ **做法**：
    - 使用宏、常量或枚举代替魔术数字。
    - 示例：

```cpp
//※直接使用数字，会使源代码难以理解和维护。如：
```

### **4.14 宏的使用**
+ **原因**：宏可能导致副作用和代码难以调试。
+ **做法**：
    1. <font style="color:#DF2A3F;">尽量使用内联函数代替宏</font>。

```cpp
inline int max(int x, int y) {
    return (x > y ? x : y);
}
```

    2. 如果必须使用宏，注意以下事项：
        * 表达式用括号括起来。

```cpp
#define ADD(x, y) ((x) + (y))
```

        * <font style="color:#DF2A3F;">避免使用简单名字（</font>如 `MAX`、`MIN`），防止命名冲突。

```cpp
#define LIBRARY_MAX(x, y) ((x) > (y) ? (x) : (y))
```

在C/C++编程中，宏（Macro）和内联函数（Inline Function）都可以用来优化代码性能或简化代码书写，但它们的本质、使用方式以及优缺点有显著的区别。以下从多个角度详细分析两者的区别：

---

#### 1. 定义与实现方式
+ **宏**：
    - 宏是通过预处理器（Preprocessor）实现的。
    - 使用`#define`定义宏，它是一种文本替换机制，在编译之前由预处理器直接将宏名替换为对应的代码。
    - 示例：

```c
#define SQUARE(x) ((x) * (x))
```

在代码中调用`SQUARE(5)`时，预处理器会将其替换为`((5) * (5))`。

+ **内联函数**：
    - 内联函数是通过编译器实现的。
    - 使用`inline`关键字声明，编译器会尝试将函数体直接嵌入到调用处，从而避免函数调用的开销。
    - 示例：

```cpp
inline int square(int x) {
    return x * x;
}
```

---

#### 2. 类型检查
+ **宏**：
    - 宏没有类型检查机制，因为它只是简单的文本替换。
    - 如果参数类型不匹配，可能会导致难以发现的错误。
    - 示例：

```c
#define SQUARE(x) ((x) * (x))
int result = SQUARE("hello"); // 编译可能不会报错，但运行时会出错
```

+ **内联函数**：
    - 内联函数具有严格的类型检查，因为它是标准的函数定义。
    - 如果传递的参数类型不符合函数签名，编译器会报错。
    - 示例：

```cpp
inline int square(int x) {
    return x * x;
}
int result = square("hello"); // 编译器会报错
```

---

#### 3. 作用域
+ **宏**：
    - 宏的作用域从定义点开始，直到文件结束，或者被`#undef`取消定义。
    - 宏没有命名空间的概念，容易引发命名冲突。
+ **内联函数**：
    - 内联函数遵循C++的作用域规则，可以定义在类、命名空间或局部作用域中。
    - 更加安全，不容易引发命名冲突。

---

#### 4. 调试难度
+ **宏**：
    - 因为宏是预处理器阶段的文本替换，调试时无法看到宏展开后的代码。
    - 如果宏定义复杂，可能会导致难以定位问题。
+ **内联函数**：
    - 内联函数是正常的函数，调试时可以看到完整的函数调用栈。
    - 即使编译器未将其内联化，也可以正常调试。

---

#### 5. 性能
+ **宏**：
    - 宏本身没有性能开销，因为它只是简单的文本替换。
    - 但是，如果宏定义不当，可能会导致代码膨胀或重复计算。例如：

```c
#define SQUARE(x) ((x) * (x))
int result = SQUARE(a + b); // 展开后为 ((a + b) * (a + b))，可能导致重复计算
```

+ **内联函数**：
    - 内联函数避免了函数调用的开销，但是否真正内联取决于编译器的优化决策。
    - 内联函数通常比宏更安全，且不会导致重复计算。

---

#### 6. 可读性与维护性
+ **宏**：
    - 宏定义简单直观，但对于复杂的逻辑，宏可能会降低代码的可读性和维护性。
    - 由于缺乏类型检查和作用域控制，容易引入潜在的错误。
+ **内联函数**：
    - 内联函数更加规范，符合函数式编程的思想，代码可读性更高。
    - 维护起来也更加方便，尤其是在团队协作中。

---

#### 7. 适用场景
+ **宏**：
    - 适用于简单的常量定义或简单的表达式替换。
    - 示例：

```c
#define PI 3.14159
#define MAX(a, b) ((a) > (b) ? (a) : (b))
```

+ **内联函数**：
    - 适用于需要类型检查的小型函数，尤其是那些频繁调用但逻辑简单的函数。
    - 示例：

```cpp
inline double area(double radius) {
    return PI * radius * radius;
}
```

---

#### 总结对比表
| 特性 | 宏 | 内联函数 |
| --- | --- | --- |
| **实现方式** | 预处理器文本替换 | 编译器内联优化 |
| **类型检查** | 无 | 有 |
| **作用域** | 全局 | 符合C++作用域规则 |
| **调试难度** | 较高 | 较低 |
| **性能** | 无函数调用开销，但可能膨胀 | 无函数调用开销，安全性更高 |
| **可读性与维护性** | 较差 | 较好 |
| **适用场景** | 简单常量或表达式替换 | 小型函数，需类型检查的场景 |


---

#### 结论
在现代C++开发中，推荐优先使用内联函数而非宏，因为内联函数更加安全、可读性更高，并且支持类型检查。宏虽然在某些场景下仍然有用，但由于其缺乏类型安全性和作用域控制，应谨慎使用。
